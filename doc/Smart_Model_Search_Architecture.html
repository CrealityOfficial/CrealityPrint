1. 需求概述

🎯 核心目标

让AI能够理解用户的模型需求，自动在模型库中搜索、筛选、下载并导入最匹配的模型，实现"一句话打印"的极致体验。

意图解析

本地缓存检查

3
智能搜索排序
调用模型库API，按指定规则排序返回结果
4
自动下载
选择Top1模型，异步下载并实时反馈进度
5
自动导入
下载完成后自动调用切片器导入功能

5. 模型库API设计（实际实现）

✅ 已实现

使用创想云现有的三个API完成全流程，无需开发新API。

5.1 搜索模型组接口

// POST /api/cxy/search/model
// 请求Body
{
    "page": 1,
    "pageSize": 1,
    "keyword": "拉布布",
    "sortType": 7,       // 1=点赞, 3=最新, 7=下载, 8=综合
    "isAsc": false,
    "hasCfgFile": 1       // 只返回有配置文件的模型
}

// 响应示例
{
    "code": 0,
    "result": {
        "list": [
            {
                "id": "model_group_xxx",     // 模型组ID
                "groupName": "拉布布",
                "likeCount": 341,
                "downloadCount": 121309,
                "covers": [...]
            }
        ]
    }
}

5.2 获取3mf列表接口

// POST /api/cxy/v3/model/3mfList
// 请求Body
{
    "modelGroupId": "model_group_xxx",  // 从搜索接口获取
    "page": 1,
    "pageSize": 1
}

// 响应示例
{
    "code": 0,
    "result": {
        "list": [
            {
                "id": "threemf_xxx",      // 3mf文件ID
                "name": "雷电将军",
                "downloadCount": 1234,
                "thumbnail": "https://..."
            }
        ]
    }
}

5.3 获取下载链接接口

// POST /api/cxy/v3/model/3mfDownload
// 请求Body
{
    "id": "threemf_xxx"       // 3mf文件ID
}

// 响应示例
{
    "code": 0,
    "result": {
        "downloadUrl": "https://cdn.../xxx.3mf?token=xxx"  // 60分钟有效
    }
}

5.4 API调用链

sequenceDiagram participant C as MCPChatPanel participant API1 as /api/cxy/search/model participant API2 as /api/cxy/v3/model/3mfList participant API3 as /api/cxy/v3/model/3mfDownload participant Import as import_model_id C->>API1: 1. 搜索模型组 API1-->>C: 返回 modelGroupId C->>API2: 2. 获取3mf列表 API2-->>C: 返回 3mfId C->>API3: 3. 获取下载链接 API3-->>C: 返回 downloadUrl C->>Import: 4. 下载并导入

6.2 工具实现代码框架

// ModelLibraryBridge.cpp
class ModelLibraryBridge {
public:
    // 搜索模型
    SearchResult SearchModels(
        const std::string& keyword,
        const std::string& sort_by,
        int limit
    );
    
    // 下载模型
    DownloadTask DownloadModel(
        const std::string& model_id,
        std::function<void(int progress)> on_progress
    );
    
    // 导入模型到切片器
    bool ImportModel(const std::string& file_path);
    
    // 一键搜索下载导入
    ModelImportResult SearchAndImport(
        const std::string& keyword,
        const std::string& sort_rule,
        std::function<void(const std::string& stage, int progress)> on_status
    );
};

9. 安全与权限考虑

风险点 防护措施
恶意文件下载 文件类型白名单（.stl, .obj, .3mf等）、大小限制、病毒扫描
用户确认 首次自动下载需用户确认、提供"不再询问"选项
存储空间 下载前检查磁盘空间、自动清理过期缓存
网络超时 下载超时处理、断点续传、失败重试机制
API限流 请求频率限制、缓存搜索结果

# 多挤出机喷嘴组合与工艺层高过滤方案

## 1. 目标

多挤出机打印机允许每个物理挤出机独立选择喷嘴变体。喷嘴变体由喷嘴口径和流量类型共同确定，例如 `0.2-Standard`、`0.4-Standard` 和未来的 `0.2-HighFlow`。

本方案解决两个问题：

1. 禁止选择不存在共同可打印层高区间的喷嘴组合。
2. 对合法喷嘴组合，只在工艺下拉列表中展示层高参数受该组合支持的工艺。

规则由配置数据驱动，不通过打印机名称、喷嘴名称或工艺名称进行判断。

## 2. 喷嘴组合约束

每个喷嘴变体提供：

```text
min_layer_height
max_layer_height
```

所有已配置物理挤出机的公共层高区间为：

```text
组合最小层高 = max(所有已选喷嘴的 min_layer_height)
组合最大层高 = min(所有已选喷嘴的 max_layer_height)
```

组合有效条件：

```text
组合最小层高 <= 组合最大层高
```

例如 K3 同时选择：

```text
0.2-Standard：0.04～0.14 mm
0.8-Standard：0.16～0.56 mm
```

得到的组合区间是 `0.16～0.14 mm`，不存在交集，因此拒绝最后一次喷嘴切换。

## 3. 非法切换交互

喷嘴切换必须先校验候选组合，再写入项目配置：

1. 使用当前所有喷嘴选择和本次候选变体计算公共区间。
2. 没有公共区间时，不写入 `variant_index` 和 `variant_id`。
3. 下拉框继续显示切换前的值。
4. 弹窗列出造成上下限冲突的喷头、变体和支持范围。
5. 不触发重新切片、项目脏状态或工艺刷新。

禁止逻辑不能硬编码 `0.2 + 0.8`。未来 `0.2-HighFlow` 如果具有不同的层高范围，应自动按照它的实际参数参与计算。

## 4. 工艺过滤规则

喷嘴组合有效后，工艺预设必须同时满足：

```text
组合最小层高 <= layer_height <= 组合最大层高
组合最小层高 <= initial_layer_print_height <= 组合最大层高
```

过滤读取工艺配置中的有效参数，不解析类似 `0.12mm Standard` 的显示名称。

兼容性判断集中在 `PresetBundle`，`TabPresetComboBox` 和其他工艺选择入口复用同一个判断，避免不同界面出现不一致的工艺列表。

## 5. 当前工艺失效

如果喷嘴组合合法，但当前工艺不再支持公共层高区间：

1. 在当前打印机兼容且可见的工艺中查找候选项。
2. 选择与当前普通层高差值最小的工艺。
3. 差值相同时优先较小层高。
4. 用户取消已有的工艺保存或切换确认时，回退本次喷嘴变体修改。
5. 如果参数包暂时没有兼容工艺，仍允许层高区间有交集的喷嘴组合；当前工艺保留为不可用状态，等待用户调整工艺或更新参数包。

载入旧项目时，如果当前工艺不兼容，当前项可以保留显示，但标记为不可用；其他不兼容工艺从下拉列表过滤。

## 6. K3 工艺数据补充

K3 原有 0.08 和 0.12 mm 工艺的首层高度均为 0.20 mm，超过 `0.2-Standard` 的最大层高 0.14 mm。为保证合法组合至少存在可用工艺：

- 0.08 mm 工艺首层高度调整为 0.10 mm，参考 K2 Plus 0.2 喷嘴工艺。
- 0.12 mm 工艺首层高度调整为 0.12 mm，使其同时支持 `0.2 + 0.6` 的公共区间 0.12～0.14 mm。

## 7. 刷新时机

以下场景需要重新计算工艺列表：

- 切换任意物理挤出机的喷嘴变体。
- 切换打印机或恢复打印机默认喷嘴。
- 加载或恢复项目中的 `variant_index`、`variant_id`。
- 用户工艺的普通层高或首层高度发生变化。

本版本在喷嘴变体成功切换后刷新 `TabPrint` 的工艺下拉框和按挤出机参数页。

## 8. 验收场景

| 场景                 | 预期结果                                          |
| -------------------- | ------------------------------------------------- |
| K3 全部 0.4-Standard | 公共区间 0.08～0.32 mm                            |
| K3 0.2 + 0.4         | 公共区间 0.08～0.14 mm，只保留兼容工艺            |
| K3 0.2 + 0.6         | 公共区间 0.12～0.14 mm，0.12 mm 工艺可用          |
| K3 0.4 + 0.8         | 公共区间 0.16～0.32 mm，过滤 0.08 和 0.12 mm 工艺 |
| K3 0.2 + 0.8         | 无公共区间，弹窗并恢复最后一次选择                |
| 当前工艺切换后失效   | 自动选择最接近的兼容工艺                          |
| 参数包无兼容工艺     | 合法喷嘴组合仍可切换，当前工艺保留并标记为不可用  |
| 未来 0.2-HighFlow    | 按该变体自身层高范围参与组合和工艺过滤            |

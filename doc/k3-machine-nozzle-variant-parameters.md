# K3 机型喷嘴变体参数现状说明

## 1. 文档目的

本文说明当前 K3 机型参数如何表达四个物理挤出机和四种喷嘴口径，重点回答以下问题：

- 哪些参数随 `0.2 / 0.4 / 0.6 / 0.8` 喷嘴切换；
- 哪些参数只跟物理挤出机位置有关；
- 为什么 K3 运动能力参数也使用 16 项，并且不再保留普通/静音两档；
- 参数在界面修改后，切片时如何找到正确值；
- 当前仍有哪些参数值需要确认。

本文描述的是以下版本状态：

- 分支：`feature/f039_group`
- 机型参数基线 Gerrit：`41311`
- 运动能力内联界面 Gerrit：`41328`
- K3 机型预设：`resources/profiles/Creality/machine/Creality K3 0.4 nozzle.json`

## 2. 最终结论

当前 K3 机型参数按产品语义分为四类：

| 分类                               | 参数数量 | 当前状态                                           |
| ---------------------------------- | -------: | -------------------------------------------------- |
| 已完成端到端喷嘴独立               |       38 | 23 个挤出机/喷嘴参数 + 15 个运动能力参数           |
| 源码支持喷嘴独立，K3 暂未启用      |        3 | 热端升降温速率和冲刷数据集                         |
| 按物理挤出机位置保存               |        3 | `extruder_offset`、`extruder_type`、`nozzle_diameter` |
| 机器级共享                         |        — | 例如打印范围、机器 G-code、固件类型等              |

最容易记忆的原则是：

> 16项表示“喷嘴身份行”，不等于16个参数，也不等于界面显示16个输入框。

当前共有38个参数显式保存为16项，并且已经完成从机器参数界面、存储、切片物化到切片/预览消费的喷嘴独立链路。运动能力页面只显示当前实际选中的“口径 + 流量类型”组合，并将同组修改或恢复同步到 E1～E4 对应的源数据行。

这些参数统一使用一套机制：白名单声明喷嘴独立属性，挤出机页面绑定对应的喷嘴源数据行，`PresetBundle::full_fff_config()` 将16行源数据物化为4个物理喷嘴值，使用时再通过 `filament_map` 找到当前逻辑耗材对应的物理喷嘴。校准流程和设备选择对话框使用设备当前状态，不计入本文的38个机型喷嘴独立参数链路。

## 3. 16 行参数表如何定位喷嘴

K3 有四个物理挤出机，每个位置支持四种 Standard 喷嘴：

| 变体索引 | 喷嘴显示名称 | 稳定身份示例       |
| -------: | ------------ | ------------------ |
|        0 | `0.4-标准`   | `E1-N04-Standard`  |
|        1 | `0.2-标准`   | `E1-N02-Standard`  |
|        2 | `0.6-标准`   | `E1-N06-Standard`  |
|        3 | `0.8-标准`   | `E1-N08-Standard`  |

机型参数使用三个平行数组标记每一行属于哪个喷嘴：

```text
printer_extruder_id
+ printer_extruder_variant
+ printer_nozzle_variant
= 一条唯一的机器喷嘴参数行
```

当前16行的顺序固定为：

```text
E1：0.4、0.2、0.6、0.8
E2：0.4、0.2、0.6、0.8
E3：0.4、0.2、0.6、0.8
E4：0.4、0.2、0.6、0.8
```

因此数组中的第 `6` 行表示：

```text
E2 + Direct Drive Standard + 0.6 喷嘴
```

所有16项喷嘴参数必须使用完全相同的行顺序，不能单独重排。

## 4. 机器参数分类

### 4.1 已完成喷嘴独立链路的23个挤出机/喷嘴参数

以下参数在切换喷嘴口径后，会读取对应的16行源数据：

| 界面分组       | 配置参数                                  | 中文含义             |
| -------------- | ----------------------------------------- | -------------------- |
| 层高限制       | `min_layer_height`                        | 最小层高             |
| 层高限制       | `max_layer_height`                        | 最大层高             |
| 喷嘴属性       | `nozzle_volume`                           | 切刀至喷嘴出口容积   |
| 喷嘴属性       | `nozzle_type`                             | 喷嘴材质类型         |
| 回抽           | `retraction_length`                       | 回抽长度             |
| 回抽           | `retract_restart_extra`                   | 额外回填长度         |
| 回抽           | `z_hop`                                   | 回抽时抬Z            |
| 回抽           | `z_hop_types`                             | 抬Z类型              |
| 回抽           | `travel_slope`                            | 空驶抬高角度         |
| 回抽           | `retraction_speed`                        | 回抽速度             |
| 回抽           | `deretraction_speed`                      | 装填速度             |
| 回抽           | `retraction_minimum_travel`               | 空驶距离阈值         |

| 强化抬Z策略    | `retract_lift_above`                      | 仅在指定高度以上抬Z  |
| 强化抬Z策略    | `retract_lift_below`                      | 仅在指定高度以下抬Z  |
| 强化抬Z策略    | `retract_lift_enforce`                    | 仅表面抬Z            |
| 换料时回抽     | `retract_length_toolchange`               | 换料回抽长度         |

| 换料时回抽     | `long_retractions_when_cut`               | 切料时长回抽         |
| 换料时回抽     | `retraction_distances_when_cut`           | 切断回抽距离         |

`nozzle_volume` 原来位于“基础信息”，`nozzle_type` 原来位于“附件”，两者都只有一个共享输入框。当前已将它们移入“挤出机1～4”的“大小”分组，切换该挤出机的喷嘴口径时，控件直接复用已有机制并绑定对应的16行源数据。`nozzle_volume` 的冲刷计算和统计、`nozzle_type` 的切片硬度警告通过 `filament_map` 读取实际物理喷嘴的值。

`travel_slope` 和 `retract_lift_enforce` 原来虽然显示在挤出机页面，但没有进入喷嘴变体白名单。当前已经加入 `printer_options_with_variant_1`，并且控件启用状态也改为读取当前喷嘴的 `variant_i`。

### 4.2 按物理位置处理的参数

| 配置参数             | 当前含义                             | 为什么不按口径保存16份                 |
| -------------------- | ------------------------------------ | -------------------------------------- |
| `extruder_offset`    | E1～E4 的物理安装偏移                | 同一位置更换喷嘴口径不会改变安装坐标   |
| `extruder_type`      | 每个物理挤出机的驱动结构             | 描述硬件位置能力，不是喷嘴工艺值       |
| `nozzle_diameter`    | 当前四个物理位置实际选中的喷嘴口径   | 由喷嘴变体元数据和项目选择状态物化     |

`extruder_offset` 当前相同值仍可采用一个物理位置默认值，不进入16行喷嘴参数表。

这三个参数不是机器级共享参数，也不是喷嘴独立业务参数；它们描述 E1～E4 当前的硬件位置或选择状态。除此之外，未进入喷嘴变体白名单且不属于物理位置状态的参数，继续作为机器级共享参数使用。

### 4.3 源码预留、K3 暂未启用的3个参数

| 配置参数                    | K3 当前状态                                                   |
| --------------------------- | -------------------------------------------------------------- |
| `hotend_cooling_rate`       | 参数包未显式配置；默认值为 `0`；K3 G-code 未引用              |
| `hotend_heating_rate`       | 参数包未显式配置；默认值为 `0`；K3 G-code 未引用              |
| `nozzle_flush_dataset`      | 参数包未显式配置；默认值为 `0`；当前未发现 K3 消费者          |

它们已经进入源码喷嘴变体白名单，未来可以补充16项喷嘴数据，但当前只是预留能力：K3 没有可靠参数来源，也没有实际使用链路，因此不计入当前38个已配置参数。这里的“未启用”不等于“共享”；共享参数在设计上只有一份值，而这三个参数在设计上允许按喷嘴独立，只是 K3 尚未提供和使用。

## 6. 16项喷嘴身份运动能力参数

`printer_options_with_variant_2` 中共有15个运动能力参数。这个集合名称沿用 Bambu 的历史命名，但 K3 不启用 `silent_mode`，因此不再使用“每行普通/静音两个值”的步长2结构，而是与其他喷嘴独立参数一样使用步长1：

```text
16条喷嘴身份行 × 每行1个值 = 16项
```

| 参数                                    | 当前每条喷嘴身份行的值 |
| --------------------------------------- | ---------------------: |
| `machine_max_acceleration_x`            |                  20000 |
| `machine_max_acceleration_y`            |                  20000 |
| `machine_max_acceleration_z`            |                    100 |
| `machine_max_acceleration_e`            |                   5000 |
| `machine_max_acceleration_extruding`    |                  20000 |
| `machine_max_acceleration_retracting`   |                   5000 |
| `machine_max_acceleration_travel`       |                  20000 |
| `machine_max_speed_x`                   |                    800 |
| `machine_max_speed_y`                   |                    800 |
| `machine_max_speed_z`                   |                      5 |
| `machine_max_speed_e`                   |                     50 |
| `machine_max_jerk_x`                    |                    100 |
| `machine_max_jerk_y`                    |                    100 |
| `machine_max_jerk_z`                    |                      5 |
| `machine_max_jerk_e`                    |                     10 |

当前16行数值相同，表示默认运动上限一致；显式16项的目的，是让机器参数统一服从同一套喷嘴身份和保存、恢复、切片选择链路，而不是提前预留 High Flow。以后若某个喷嘴需要不同值，可直接修改对应身份行。

16 项是配置层的完整源数据，不等于界面固定显示16个输入框。运动能力页面参考工艺参数的展示方式，只显示当前有效的喷嘴组。例如：

```text
E1 = 0.2-标准
E2 / E3 / E4 = 0.4-标准

界面显示：0.2-标准、0.4-标准，共两个输入框
```

其中 `0.2-标准` 的一次修改会同步写入 E1～E4 对应的全部 `0.2-标准` 源数据行；`0.4-标准` 同理。这样既避免暴露16行内部存储细节，也保证同一种喷嘴身份只有一份产品含义明确的数值。

## 7. 界面到切片的完整链路

### 7.1 界面选择

用户在“挤出机1～4”页面选择某个喷嘴口径后：

```text
物理挤出机编号
+ 喷嘴变体索引
+ 挤出机结构/流量类型
→ printer_nozzle_variant_config_index()
→ 得到16行源数据中的具体下标
```

`TabPrinter::refresh_nozzle_variant_ui()` 将该下标设置到挤出机页面字段，同时重新计算运动能力页面当前应显示的喷嘴组。运动能力页面不按 E1～E4 重复显示，而是按“口径 + 流量类型”合并成与工艺页面一致的内联多输入框。

### 7.2 修改和恢复

挤出机页面的参数修改仍写入当前物理挤出机所选喷嘴对应的源数据行。

运动能力页面的参数修改以可见喷嘴组为单位：先写入可见输入框对应的代表行，再同步到 E1～E4 中身份相同的全部源数据行。Dirty 标识、恢复到已保存值和恢复系统值也按同一可见喷嘴组计算，避免出现“改了值没有恢复图标”或“只恢复代表行”的情况。

### 7.3 切片物化

切片前，`PresetBundle::full_fff_config()` 根据四个物理挤出机当前选择的喷嘴，从16行源数据中各选一行：

```text
机型预设中的16行源参数
→ 根据 E1～E4 当前喷嘴选择各取一行
→ 压缩为4个物理挤出机的运行时参数
→ 已完成链路的参数按实际物理喷嘴索引读取
```

例如：

```text
E1 选择0.2，E2选择0.4，E3选择0.6，E4选择0.8
→ min_layer_height = [0.04, 0.08, 0.12, 0.16]
```

上述完整链路适用于23个挤出机/喷嘴参数和15个运动能力参数。运行时参数由16项压缩为4项；需要按当前耗材消费参数时，再通过 `filament_map` 将逻辑耗材映射到物理喷嘴。运动能力的内部标记用于避免把旧式 `[普通, 静音]` 两项误判为两个喷嘴值。

运动能力、喷嘴容积和喷嘴材质共用同一个物理喷嘴索引计算函数和同一份 `filament_map` 结果，避免不同模块分别解释逻辑耗材和物理喷嘴的关系。

## 8. 与 BambuStudio 的关系

BambuStudio 的机器变体参数同样分为：

- `printer_options_with_variant_1`：每个机器变体一个值；
- `printer_options_with_variant_2`：传统热端变体的每个变体包含普通/静音两个值。

K3 在该机制上增加了喷嘴口径身份 `printer_nozzle_variant`，因此参数行身份从 Bambu 的挤出机/流量组合扩展为：

```text
物理挤出机 + 挤出机/流量类型 + 喷嘴口径变体
```

Bambu 的步长2来自历史普通/静音模式，并不表示 Standard/High Flow。K3 是 Klipper 机型，当前 `silent_mode=false`，所以采用以下兼容规则：

- 存在结构化喷嘴身份且未启用静音：步长1，16行就是16项；
- 启用了静音，或是不含K3喷嘴身份的旧式机型：继续使用 Bambu 的步长2。

这样只取消 K3 不存在的静音维度，不改变其他机型既有的数据语义。

另外，Creality 界面增加了 `travel_slope` 和 `retract_lift_enforce`。Bambu 对应版本没有在挤出机页面显示这两个参数，所以其白名单没有这两个字段；K3 当前已经补齐。

## 9. 仍需参数侧确认的数值

38个已完成喷嘴独立链路的参数中，以下数值仍需要参数或测试人员结合实际打印确认：

### 9.1 普通回抽与换料回抽

当前值为：

```text
retraction_length：         0.4/0.2/0.6/0.8 = 2/0/0/0
retract_length_toolchange： 0.4/0.2/0.6/0.8 = 0.8/0.5/1.5/3
```

需要确认普通回抽和换料回抽是否写反，特别是 `0.2/0.6/0.8` 普通回抽为零是否符合实际测试结果。

### 9.2 切断回抽距离

当前 `retraction_distances_when_cut` 四种口径全部为 `30`。历史参数曾将 `0.2` 设置为 `18`，需要确认最终实测值。

这些问题属于参数值确认，不属于喷嘴变体数据模型缺陷。确认后只需修改对应16项数组，不再需要修改源码类型或切片读取链路。

## 10. 后续参数包数据契约

源码继续允许喷嘴独立参数使用单值广播；以下是 K3 随包配置的书写规范，不是加载器对旧配置的限制。共享参数保持原样，已启用的喷嘴独立参数即使数值相同也显式保存完整数组。

以后更新 K3 机型参数时必须遵守：

1. 三个身份数组长度必须都是16，并且逐行对齐。
2. 已确认喷嘴独立的23个挤出机/喷嘴参数固定写成16项。
3. `printer_options_with_variant_2` 中的15个运动能力参数固定写成16项，每条喷嘴身份行一个值。
4. K3 不再为普通/静音重复数据，也不提前为 High Flow 预留空槽。
5. 行顺序固定为每个物理挤出机内的 `0.4、0.2、0.6、0.8`。
6. 三个未启用参数不写推测值；物理位置参数不进入16行喷嘴参数表。
7. 修改任何一项数组后，都要验证界面切换、保存恢复、重新载入和切片物化结果。

2026-09-10 复核：当前机型的 38 项已启用独立参数均已显式写成 16 项，三个身份数组逐行对齐，本次不修改机型 JSON。三个未启用参数仍不补写推测值，物理位置参数也不扩展成 16 行。

同一书写规则已应用到 6 份工艺预设和 57 份耗材预设：工艺的 41 项已接入独立参数均显式保存 16 项，耗材的 23 项已接入独立参数均显式保存 4 项。行数不同来自各自的身份维度，不是不一致。经用户确认，`0.08mm`、`0.24mm` 工艺的两个历史共享数组已按 `0.24mm` 当前生效值恢复为单值（减速比例 `100%`、底壳 `7` 层），Generic PLA 的 PA 已恢复历史共享单值（关闭、系数 `0.04`）；其余共享参数保持原样。具体说明分别记录在工艺、耗材文档中。

## 11. 建议验证清单

- E1 分别选择 `0.2/0.4/0.6/0.8`，确认23个挤出机/喷嘴参数显示对应行。

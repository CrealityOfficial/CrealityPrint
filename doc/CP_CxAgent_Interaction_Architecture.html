CP 与 CxAgent 交互工作原理

CP (Creality Print) 是创想三维的切片软件客户端，CxAgent 是智能代理服务器。两者通过 WebSocket 和 HTTP 进行通信，实现智能化的切片、打印等操作辅助功能。

6. 总结

CP 与 CxAgent 的交互基于客户端 - 代理架构，通过以下关键技术实现智能化交互：

  • 双通道通信: WebSocket（实时消息）+ HTTP（RESTful 请求）
  • 智能状态同步: 300ms 自动推送，确保 CxAgent 始终有最新上下文
  • 工具契约化: 通过 requires/provides/invalidates 明确定义工具语义
  • 自动错误修复: 基于 remediations 配置的智能化纠错机制
  • 进度可视化: 分阶段实时汇报（5% → 50% → 100%）

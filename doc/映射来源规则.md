
### 当前映射规则

应该把“映射来源”和“模式判断”分开：

- `filament_map` 的来源只看是否载入了完整 3MF：完整 3MF 优先使用项目中保存的映射；导入普通模型或新建项目时，才按通用规则生成映射。
- `filament_map_mode` 只看当前喷嘴信息：所有喷嘴口径、流量类型均相同为 `AutoForSaving`；任一喷嘴口径或流量类型不同为 `Manual`。

“喷嘴相同/不同”在本文中均指 `has_mixed_selected_nozzle_variants()` 的判断结果，即同时比较喷嘴口径和流量类型。

#### 初次载入后的规则

| 来源                    | 当前喷嘴信息 | 使用的映射                                   | `filament_map_mode` | 点击切片后的行为                           |
| -----------------------| -----------| --------------------------------------------| ------------------- | ----------------------------------------|
| 导入完整 3MF            | 相同        | 优先使用 3MF 保存的 `filament_map`，不重新覆盖  | `AutoForSaving`     | 直接切片，不显示映射弹窗                     |
| 导入完整 3MF            | 不同        | 优先使用 3MF 保存的 `filament_map`            | `Manual`            | 打开映射弹窗；不兼容项标红并阻止确认，由用户调整 |
| 导入普通模型 / 新建项目   | 相同        | 按通用规则生成 `automatic_map`                | `AutoForSaving`     | 直接切片                                   |
| 导入普通模型 / 新建项目   | 不同        | 按通用兼容规则生成手动弹窗的初始映射，跳过不兼容喷嘴 | `Manual`           | 打开映射弹窗，由用户检查或拖拽后确认            |

#### “通用规则”的具体定义

这里的“通用规则”和“通用兼容规则”使用同一个自动计算算法，区别只在于计算结果的用途：

- 喷嘴信息相同时，计算结果直接作为本次切片使用的 `automatic_map`。
- 喷嘴信息不同时，计算结果只作为手动弹窗的推荐初始映射，用户确认后才成为最终手动映射。

当前算法的具体步骤如下：

1. 确定本次需要处理的耗材。
   - 单盘切片：取当前盘实际使用的耗材。
   - 所有盘切片：取所有相关盘实际使用的耗材。
   - 混色耗材先展开为对应的物理耗材 ID。
2. 判断每个物理喷嘴是否兼容当前工艺。
   - 同时检查普通层高 `layer_height` 和首层层高 `initial_layer_print_height`。
   - 两个层高都必须落在该喷嘴允许的最小、最大层高范围内。
   - 未配置最小层高时，使用 `喷嘴口径 × 0.2`。
   - 未配置最大层高时，使用 `喷嘴口径 × 0.75`。
3. 按物理喷嘴编号从小到大生成“兼容喷嘴列表”，不兼容喷嘴不进入该列表。
4. 按本次使用的耗材顺序，在兼容喷嘴列表中循环分配。
5. 如果没有任何兼容喷嘴，则停止切片并提示当前工艺层高与所有喷嘴均不兼容。

例如，4 个喷嘴中只有喷嘴 2、3 兼容，当前使用耗材为 1、2、3、4，则生成：

```text
兼容喷嘴列表 = [2, 3]
automatic_map = [2, 3, 2, 3]
```

因此，无论自动切片还是生成手动弹窗的初始映射，都不会把本次使用的耗材分配到喷嘴 1、4。

当前兼容性判断只包含“工艺层高是否适配喷嘴”。耗材类型、耗材颜色和喷嘴流量类型目前不参与自动分配；喷嘴流量类型只参与“喷嘴信息是否相同”的模式判断。若后续需要增加材料、硬度或流量兼容性，应扩展兼容性输入，不能直接把它描述成当前已有规则。

#### 手动弹窗初始映射规则

载入入口负责记录当前映射是否必须保留；手动弹窗不能通过“`filament_map` 非空”推断来源：

1. 导入完整 3MF 时，直接把 3MF 的 `filament_map` 写入当前项目配置。即使喷嘴调整后暂时不兼容，也保留该映射；弹窗显示冲突、标红并阻止确认，等待用户修正。
2. 导入普通模型或新建项目时，可以先生成一份默认映射；但喷嘴或工艺可能在载入后继续变化，因此进入混合喷嘴手动弹窗前，只要当前映射不是来自完整 3MF、也不是用户已经确认的手动映射，就必须按当前配置重新生成 `automatic_map` 作为弹窗初始布局。
3. 用户在手动弹窗确认后，直接用确认结果更新当前 `filament_map`，之后按用户已确认的映射处理；若配置变化导致冲突，则保留映射并要求用户修正。

完整 3MF 与普通模型的区分应直接使用载入入口：完整项目会执行 `LoadConfig`，普通模型只执行 `LoadModel`。运行期间只需保存“当前映射是否必须保留”的布尔状态，不新增 `FilamentMapSource` 枚举，也不写入新的 3MF 字段。不能使用“`filament_map` 非空”代替载入入口判断，因为配置默认值就是 `{1}`，普通模型场景同样可能得到非空映射。

#### 导入完整 3MF 后调整喷嘴

调整喷嘴后不丢弃 3MF 映射。映射继续沿用导入时的 `filament_map`，或用户后来已经确认过的最新手动映射；模式和切片入口则按调整后的喷嘴信息重新判断。

| 调整前 | 调整后                              | 映射处理                               | 调整后的 mode   | 点击切片后的行为               |
| ------ | ----------------------------------| --------------------------------------| ---------------| ------------------------------ |
| 相同   | 仍相同（例如全部喷嘴统一改为另一口径）   | 保留 3MF 映射，不重新自动分配             | `AutoForSaving`| 直接切片                       |
| 相同   | 变为不同                            | 保留 3MF 映射                          | `Manual`       | 打开映射弹窗；冲突项由用户修正 |
| 不同   | 变为相同                            | 保留 3MF 映射或最新确认映射，不重新自动分配 | `AutoForSaving`| 直接切片                       |
| 不同   | 仍不同（更换了部分喷嘴）               | 保留 3MF 映射或最新确认映射              | `Manual`       | 打开映射弹窗；冲突项由用户修正 |

这里的核心是：喷嘴调整只改变 mode 和切片入口，不把“来自完整 3MF 的映射”误当成普通模型的默认映射并覆盖掉。

#### 调整喷嘴后重新保存 3MF

保存 3MF 时，应保存当前保留或已经确认的 `filament_map`，并根据保存时的最终喷嘴信息写入对应 mode。保存动作本身不重新自动分配耗材。

| 保存时的喷嘴信息      | 保存的 `filament_map`           | 保存的 mode     | 下次重新打开后的行为                                           |
| -------------------| -------------------------------| --------------- | -------------------------------------------------------------- |
| 相同                | 当前保留的 3MF 映射，或最新确认映射 | `AutoForSaving` | 优先读取该映射；若喷嘴仍相同，直接切片                         |
| 不同，且用户已确认弹窗 | 用户确认后的手动映射              | `Manual`        | 优先读取该映射；点击切片时仍打开手动映射弹窗                   |
| 不同，但尚未确认弹窗  | 当前保留的映射，不静默改写用户映射   | `Manual`        | 优先读取该映射；点击切片时打开弹窗，不兼容项继续提示并阻止确认 |

因此，重新打开保存后的 3MF 时，仍先恢复 3MF 的 `filament_map`；随后再根据当时实际载入的喷嘴信息决定 `AutoForSaving` 或 `Manual`。如果重新打开后再次修改喷嘴，则重新套用上一张“导入完整 3MF 后调整喷嘴”表。

以上是当前确认的业务规则，也是后续代码实现和回归测试的验收口径。不能仅通过“`filament_map` 非空”判断它来自完整 3MF，因为普通模型场景也可能带有默认值。









### 当前代码需要调整的地方

#### 1. 在载入阶段准备好 `filament_map`

直接使用已有的载入方式区分映射来源：

```text
LoadModel + LoadConfig（完整 3MF） -> 使用 3MF 保存的 filament_map
LoadModel（普通模型）             -> 按通用规则生成 automatic_map
新建项目                           -> 按通用规则生成 automatic_map
```

完整 3MF 当前已经在 `bbs_3mf.cpp` 中读取并校验完整映射，这条链路应继续保留 3MF 的 `filament_map`。

普通模型或新建项目先调用自动算法生成默认映射，并写入 `project_config.filament_map`、`filament_map_2` 和 `filament_volume_map`。由于喷嘴和工艺仍可能在载入后变化，这份结果不能被视为永久有效；进入混合喷嘴弹窗前还要按当前配置刷新推荐初始映射。

#### 2. 修改 `FilamentPanel::prepare_filament_nozzle_mapping_for_slice()`

该入口继续只根据当前喷嘴信息决定 mode：

```text
喷嘴信息相同   -> AutoForSaving，不弹窗
喷嘴信息不同   -> Manual，打开手动弹窗
```

喷嘴信息相同时保留载入阶段已经准备好的当前映射，只同步为 `AutoForSaving` 后直接切片；喷嘴信息不同时同步为 `Manual` 并打开弹窗。

#### 3. 修改 `FilamentPanel::show_filament_grouping_dialog()`

不能使用下面的条件判断映射来源：

```cpp
saved_map_option != nullptr && !saved_map_option->values.empty()
```

这会把普通模型场景的默认 `{1}` 或过期自动映射错当成需要保留的映射。弹窗应按载入入口记录的布尔状态处理：

```text
完整 3MF 或用户已确认映射 -> 使用当前 filament_map
普通模型且尚未确认       -> 按当前兼容喷嘴重新生成 automatic_map
```

重新生成时必须使用弹窗打开时的当前层高、喷嘴口径及允许层高范围。用户确认后写回 `filament_map`，并把当前映射标记为需要保留。

#### 4. `Print::apply()` 只校验并消费最终映射

普通模型或新建项目已经在载入阶段生成 `filament_map`，完整 3MF 也已经恢复了文件中的 `filament_map`。因此进入 `Print::apply()` 后，映射已经确定。

对于支持喷嘴耗材映射的机型，`Print::apply()` 即使读取到 `AutoForSaving`，也只使用手动映射校验路径检查当前映射的完整性、喷嘴范围和层高兼容性，不再执行循环分配。这里的校验路径不会修改实际保存的 mode：

```text
项目中的 mode  = AutoForSaving
切片后端行为    = 校验并使用当前 filament_map
写入结果的 mode = AutoForSaving
```

这样 mode 只是当前喷嘴组合对应的结果标记，不会成为切片阶段再次覆盖映射的原因。

#### 5. 保存 3MF 前同步 mode

`Plater::export_3mf()` 当前直接从 `full_config_secure()` 取得待保存配置。如果用户修改喷嘴后没有先切片，项目配置中的 mode 可能仍是旧值。

生成待保存配置前应按当前喷嘴信息同步：

```text
喷嘴信息相同   -> filament_map_mode = AutoForSaving
喷嘴信息不同   -> filament_map_mode = Manual
```

这里只更新 mode、`filament_map_2` 等派生数据，不重新自动分配 `filament_map`。保存成功后，当前映射成为该 3MF 的项目映射。

#### 建议修改范围

- `src/libslic3r/PresetBundle.hpp/.cpp`：为普通模型或新建项目生成完整兼容映射，并提供保存前的 mode 同步入口。
- `src/slic3r/GUI/Plater.cpp`：在普通模型首次载入空项目、新建项目时生成默认映射，并在完整 3MF 载入后及保存前同步 mode。
- `src/slic3r/GUI/FilamentPanel.h/.cpp`：切片时只按喷嘴信息分流；手动弹窗直接使用当前已准备好的 `filament_map`。
- `src/libslic3r/Print.cpp`：校验并消费已经准备好的最终映射，避免按 mode 二次覆盖。

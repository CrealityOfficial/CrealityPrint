## 2. 问题现象

- 用户反馈：旧版本一直存在的悬垂速度说明，在当前界面中悬停时不再显示；桥接右侧“外部／内部”仍有提示，但存在提示内容与标签不对应的问题。
- 实际结果：悬垂速度没有显示原有说明；桥接截图显示 `bridge_speed#0` 的说明，未按命中的内部参数选择内容。
- 期望结果：恢复旧版本已有的提示内容，左侧分组和右侧标签均能显示正确说明；不新增或改写业务文案，不影响参数值。
- 此问题属于参数悬停说明，与 Bug 17981 的“未保存修改”弹窗不是同一问题。

## 4. 根因分析

### 触发条件

工艺参数经过内联多喷嘴布局改造，原有组合行被拆分，再按喷嘴重新构建悬垂速度和桥接组合行。

### 代码链路与问题原因

1. 旧版 `Tab.cpp` 在组合行 `Line` 上直接设置悬垂速度和桥接的分组说明。悬垂各档在 `PrintConfig.cpp` 中的独立 `tooltip` 原本已被注释，旧提示依靠组合行提供，并不代表旧版没有提示。
2. 内联多喷嘴改造移除了上述组合行声明，改为逐项 `append_single_option_line()`，原来的分组说明未被保留。
3. 当前 `ConfigOptionsGroup::refresh_overhang_layout()` 重新组合各喷嘴行时，使用 `original.label_tooltip`。悬垂第一项说明为空，因此组合后的悬垂说明也为空；桥接则取到了外部桥接的说明，不能代表整个分组。
4. `OG_CustomCtrl::CtrlLine::draw_text()` 原先只要文字宽度大于零就更新 `rect_label`，右侧子标签会覆盖左侧主标题的命中区域。
5. `OG_CustomCtrl::OnMotion()` 原先固定取组合行第一个参数的身份和行说明，无法区分“外部／内部”或各档标签。
6. `ProcessTip::ShowTip()` 原先主要以标题判断提示是否变化，参数身份或正文变化时可能未及时刷新。

## 5. 修复方案

### 修复思路

原样恢复旧版已有的两段分组说明及中文翻译，修复公共提示的命中与内容选择，不重新编写业务说明。

### 修改点

- `src/slic3r/GUI/OptionsGroup.cpp`
  - 按喷嘴重建组合行时，直接复用旧版 `Tab.cpp` 的悬垂速度、桥接分组说明。
  - 保留喷嘴配置名称及现有参数排列。
- `src/slic3r/GUI/OG_CustomCtrl.hpp`、`src/slic3r/GUI/OG_CustomCtrl.cpp`
  - 主标题和各子标签分别记录命中区域；右侧标签不再覆盖主标题区域。
  - 子标签根据对应 `Option` 获取已有说明、参数身份和关联提示信息；独立说明为空时复用原有分组说明。
  - 桥接“外部／内部”分别显示已有的外部、内部桥接说明；悬垂各档复用原有悬垂说明。
  - 左侧组合行显示分组说明，不冒用第一个参数名。
  - 更新和清理悬停高亮状态，使用实际命中区域控制提示位置与停留。
- `src/slic3r/GUI/MarkdownTip.hpp`、`src/slic3r/GUI/MarkdownTip.cpp`
  - 比较标题、参数身份、正文、图片和链接，目标内容变化时刷新提示。
  - 空说明不残留旧提示；没有单个参数身份的分组说明隐藏参数名行。
- `localization/i18n/zh_CN/CrealityPrint_zh_CN.po`
  - 重新启用已被标记为废弃的两条原有翻译，原文和译文不变。

最终补丁不修改 `PrintConfig.cpp`，不新增悬垂速度业务文案，不修改速度值、喷嘴映射或切片算法。

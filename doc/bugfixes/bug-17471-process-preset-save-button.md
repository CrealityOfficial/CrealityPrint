# Bug 17471 修复记录：工艺参数缺少保存按钮

## 1. 基本信息

- Bug ID：`17471`
- 标题：`工艺参数中缺少保存按钮无法保存工艺参数 如图`
- 日期：`2026-07-28`
- 所属产品：`Creality Print`
- 所属模块：`准备页面`
- 所属计划：`CP 7.2.1`
- 影响版本：`CrealityPrint_7.2.1.5429_Beta`
- 状态：`激活`
- 严重程度：`严重`
- 优先级：`高`
- 创建人：`檀献祖`
- 指派给：`贺淼`

## 2. 问题现象

- 准备页面的工艺参数区域缺少保存按钮。
- 用户修改工艺参数后，无法通过该入口保存当前工艺预设。
- 切换到用户自定义工艺预设后，删除按钮同样不显示，无法从该入口删除预设。
- 禅道期望：保存按钮显示正常。

## 3. 影响范围

- 模块：准备页面工艺参数预设工具栏。
- 关键文件：
  - `src/slic3r/GUI/Tab.cpp`
- 受影响流程：
  - 工艺预设参数修改后的保存。
  - 用户自定义工艺预设的删除。
  - 在工艺预设内搜索参数并退出搜索后的保存。
- 不在本次修改范围：
  - 机型管理页面的预设工具栏。
  - 耗材管理页面的预设工具栏。

## 4. 修复前复现步骤

1. 启动 `CrealityPrint_7.2.1.5429_Beta`，进入准备页面。
2. 展开工艺参数区域。
3. 查看工艺预设下拉框右侧的操作按钮。
4. 结果：回退按钮与搜索按钮之间的保存按钮未显示，无法从该入口保存工艺参数。
5. 切换到用户自定义工艺预设，删除按钮也不显示。
6. 期望：保存按钮正常显示；用户自定义工艺预设同时显示删除按钮。

## 5. 根因分析

- 以下根因根据当前代码和 Git 历史推断，禅道页面未直接给出原因。
- 提交 `29d8e93f4b8` 为修复机型管理页和耗材管理页在退出搜索后错误显示删除按钮，对三套相似的预设页布局统一增加了隐藏逻辑。
- 该提交误将通用 `Tab::create_preset_tab()` 中的 `m_btn_save_preset` 也在初始化时永久隐藏，同时删除了退出搜索时恢复显示保存按钮的代码。
- 同一提交还把 `Tab::update_btns_enabling()` 中“仅用户工艺预设可删除”的条件判断替换为无条件隐藏，导致删除按钮也无法进入可见状态。
- 通用 `Tab::create_preset_tab()` 正是准备页面工艺参数使用的布局，因此保存按钮和用户工艺预设的删除按钮均不再正常显示。
- 问题与 wxWidgets 3.3 的控件尺寸或布局计算无关；升级后观察到的界面缺口实际由上述显式 `Hide()` 调用造成。

## 6. 修复策略

- 仅恢复通用工艺预设页的保存按钮显示：
  - 移除 `Tab::create_preset_tab()` 初始化阶段对保存按钮的永久隐藏。
  - 退出参数搜索时调用 `m_btn_save_preset->Show()`，恢复搜索前的工具栏状态。
- 恢复删除按钮原有显示条件：仅当页面类型为 `TYPE_PRINT`，且当前预设既不是默认预设也不是系统预设时显示。
- 保留 `TabFilament::create_preset_tab()` 和 `TabPrinter::create_preset_tab()` 中的隐藏逻辑，避免重新引入机型/耗材管理页按钮误显问题。
- 不修改保存/删除按钮原有事件绑定以及 `save_preset()`、`delete_preset()` 业务流程。

## 7. 代码变更摘要

- 文件：`src/slic3r/GUI/Tab.cpp`
  - 删除通用工艺页创建保存按钮后的 `Hide()` 调用。
  - 在 `wxCUSTOMEVT_EXIT_SEARCH` 处理函数中恢复保存按钮显示。
  - 在 `update_btns_enabling()` 中按工艺预设类型和来源恢复删除按钮可见性。
  - 未修改机型页、耗材页的保存/删除按钮可见性逻辑。

## 9. 回滚与风险

- 回滚方式：恢复通用 `Tab::create_preset_tab()` 的保存按钮隐藏逻辑、移除退出搜索时的 `Show()` 调用，并将删除按钮恢复为无条件隐藏。
- 风险等级：低。
- 主要风险：三套预设页布局代码相似，后续调整按钮可见性时可能再次扩大修改范围。
- 观察点：不同主题、DPI 和窗口宽度下保存按钮的位置及搜索前后可见性。

## 10. 后续建议

- 将工艺、机型和耗材预设工具栏的按钮可见性规则拆分为明确的页面级策略，避免在相似代码中批量修改时相互影响。
- 为“进入搜索/退出搜索后工具栏状态恢复”补充 UI 回归用例。

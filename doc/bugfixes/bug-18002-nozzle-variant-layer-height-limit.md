# Bug 18002 多口径层高上限校验修复说明

## 1. 基本信息
- Bug ID：18002
- 标题：【急】【多口径】设置4个0.8口径，层高合法区间应该是[0.16,0.56]，但是不允许设置0.4层高
- 禅道链接：未提供
- 反馈人：李佳沁（创建人）
- 处理人：wangwenbin
- 分支：release-260930
- 影响模块：工艺参数编辑、喷嘴规格对应的层高上限校验

## 2. 问题现象
- 用户反馈现象：Creality K3 的四个喷嘴均选择 0.8-标准，工艺层高设置为 0.4 mm 时弹出警告。
- 实际结果：提示“层高过大，重置为 0.320”，将合法层高按 0.32 mm 上限处理。
- 期望结果：当前四个 0.8 喷嘴对应层高范围为 [0.16, 0.56] mm，允许设置 0.4 mm。

## 3. 复现步骤
- 前置条件：Creality K3；四个喷嘴均选 0.8-标准。截图工艺为 0.28mm Standard @Creality K3，耗材包含 Hyper PLA、CR PETG；具体模型文件未提供。
1. 在打印机喷嘴选择区域，将四个喷嘴均设置为 0.8-标准。
2. 打开打印机设置，查看对应喷嘴的最小层高 0.16 mm、最大层高 0.56 mm。
3. 返回全局工艺参数，将层高改为 0.4 mm，并结束输入以触发校验。
4. 观察“层高过大，重置为 0.320”的警告。
- 复现结果：见用户提供的截图；本次未运行程序独立复现。
- 复现概率：未提供。

## 4. 根因分析
- 触发条件：当前选择的喷嘴规格对应层高上限高于原始预设第 0 项，输入层高超过第 0 项上限。
- 代码链路：工艺页更新调用 `ConfigManipulation::update_print_fff_config()`，原逻辑通过 `printers.get_edited_preset().config.opt_float("max_layer_height", 0)` 固定读取原始数组第 0 项。
- K3 原始预设按喷嘴规格存储层高参数，各挤出机的 0.4、0.2、0.6、0.8 规格分别对应上限 0.32、0.14、0.42、0.56 mm。第 0 项为 0.4 规格的 0.32 mm，不代表当前选择的 0.8 规格。
- 打印机设置页已按当前喷嘴规格映射参数行，因此显示 0.56；旧校验仍读取 0.32，导致 `0.4 > 0.32` 被误判。
- `PresetBundle::full_config()` 已执行喷嘴规格参数映射；`Tab.cpp` 的层高编辑校验也已使用该有效配置中的最大上限。

## 5. 修复方案
- 修复思路：复用已有有效配置映射，与工艺编辑页现有上限规则保持一致。
- 修改文件：`src/slic3r/GUI/ConfigManipulation.cpp`。
- 移除仅用于该判断的原始打印机预设副本。
- 从 `PresetBundle::full_config()` 读取 `max_layer_height`，取当前各物理喷嘴已选规格对应上限的最大值；缺少选项或数组为空时使用 0，避免解引用空数组并沿用现有条件跳过本段上限判断。
- 不对原始预设中所有可选规格取最大值：四个 0.4 喷嘴仍得到 0.32，四个 0.8 喷嘴得到 0.56。
- 工艺编辑阶段不推断未来实际使用的喷嘴。混合口径时允许输入不代表所有喷嘴均支持打印；实际打印兼容性继续由切片阶段依据对象、耗材及喷嘴映射校验。
- 保留现有 `max_lh > 0.2` 条件、提示与回写流程；本次不扩展最小层高、首层层高或历史小口径校验规则。

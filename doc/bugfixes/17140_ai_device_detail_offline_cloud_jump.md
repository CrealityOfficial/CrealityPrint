# 17140 广域网场景下 AI 发送打印成功后未跳转到（云端）设备详情页

## 1. 基本信息
- Bug ID：17140
- 标题：广域网场景下通过 AI 发送打印时，发送打印成功却没有跳转到设备详情页
- 反馈人：测试反馈
- 处理人：
- 影响模块/影响文件：`src/slic3r/GUI/simple/sendWorkflow/EasyPrintSender.cpp`

## 2. 现象与复现
- 复现场景：AI(Beta) 模式下，同一台设备同时存在局域网连接（deviceType=0）与创想云绑定连接（deviceType=1），二者 mac 相同。当局域网连接离线（或已在设备列表中删除）、而云端绑定连接仍在线时，进入"设备"界面自动跳转设备详情页；也可通过 AI 发送打印后触发跳转。
- 实际结果：
  - 局域网设备离线但仍在列表：跳转到离线的局域网详情页（tab 标题显示局域网地址，如 `172.23.1.119`），页面无法正常交互。
  - 局域网设备已删除、仅剩在线云端设备：不跳转 / 打不开任何详情页。
- 期望结果：局域网连接离线或不存在、而云端绑定连接在线时，应打开云端（创想云）在线设备的详情页；局域网连接在线时保持原有行为不变（仍打开局域网详情）。

## 3. 责任提交追溯
- 问题位于 `EasyPrintSender::getDeviceIp()` 的当前设备地址解析逻辑，历史实现直接读取持久化文件 `deviceInfo.json` 选址，无对应的追溯 commit。

## 4. 根因分析
- 触发条件：当前设备存在局域网、云端两条同 mac 连接，且局域网连接离线或已被删除。
- 代码链路：进入设备页 → `PrinterMgrView::on_switch_to_device_page()` → `EasyPrintSender::getDeviceIp()` 取地址 → `jumpToDeviceDetail(ip, name)` 发送 `forward_device_detail`（携带该 ip）→ DMgr 前端据此打开对应地址的详情页。
- 为什么会出现该现象：`getDeviceIp()` 直接读取持久化的 `deviceInfo.json`，按 `current_device.mac` 遍历分组，命中第一个 mac 匹配项就返回其 `address`。该文件是持久化配置，不含可靠的实时 `online` / `deviceType` 字段，且局域网条目通常排在前面，因此：
  - 局域网离线时仍返回局域网地址 → 跳转到离线局域网详情页；
  - 局域网被删后该地址失效 / 无法命中有效在线连接 → 打不开详情页。
- 关键点：`DM::DataCenter`（由前端 `update_devices` 实时更新）中的 `_get_acive_device()` 已实现正确的当前设备选取优先级（局域网与云端并存时，局域网在线返回局域网、否则返回云端；仅云端时返回云端），但 `getDeviceIp()` 完全没有使用这份实时数据。

## 5. 修复方案
- 修复思路：让 `getDeviceIp()` 优先使用 `DM::DataCenter` 的实时当前设备数据来解析地址，复用其已有的"局域网在线优先、否则回退云端"的选取逻辑；仅当 DataCenter 无有效实时数据时，才回退到读取持久化 `deviceInfo.json`。
- 修改点（`EasyPrintSender::getDeviceIp()`）：
  - 新增前置分支：`DM::DataCenter::Ins().get_current_device_data()`，当 `cur_dev.valid && !cur_dev.address.empty()` 时直接返回 `cur_dev.address`。该地址已由 `_get_acive_device()` 按在线优先级选好——局域网离线/不存在且云端在线时返回云端地址。
  - 保留原读取 `deviceInfo.json` 的逻辑作为回退（DataCenter 无实时数据时的兜底），仅返回当前设备地址，不再承担在线优先级判断。

## 6. 影响范围与风险
- 正向影响：局域网离线或已删除、而云端绑定在线时，进入设备详情自动打开云端在线详情页，可正常交互。
- 是否改变旧行为：局域网连接在线时，`_get_acive_device()` 仍返回局域网地址，跳转行为完全不变；仅云端、仅局域网等既有场景行为一致。
- 可能风险：极低。DataCenter 无实时数据的极端场景下自动回退到原有文件读取逻辑，不会比修复前更差。

## 7. 回归建议
- 必测场景：同一设备局域网离线 + 云端在线，进入设备界面 / AI 发送打印后，确认打开的是云端在线详情页（tab 非局域网地址）。
- 必测场景：删除局域网设备、仅保留在线云端设备，切换到该机型后进入设备界面，确认自动打开云端详情页。
- 必测场景：局域网连接在线，确认仍打开局域网详情页，行为不变。
- 边界场景：仅云端设备（无局域网连接）、仅局域网设备（无云端绑定），确认分别打开各自详情页。
- 反向场景：局域网、云端均离线时，确认行为与修复前一致（不误跳转）。

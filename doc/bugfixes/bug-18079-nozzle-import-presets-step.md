# Bug 修复记录：创建喷嘴缺少导入预设步骤

- 标题：【引入】【创建喷嘴】在创建喷嘴页面中选择机型点击确认后没有转入到第二步导入预设页面 如图

## 2. 问题现象

创建喷嘴时，选择机型并点击第一页“确认”后，未进入第二步“导入预设”。用户无法按截图所示选择参考机型、材料预设和工艺预设。

## 3. 影响范围

- 模块：准备页面的创建喷嘴对话框。
- 文件：`src/slic3r/GUI/CreatePresetsDialog.cpp`、`src/slic3r/GUI/CreatePresetsDialog.hpp`。
- 涉及流程：第一页确认、第二步预设导入、返回修改机型或喷嘴后再次进入、最终创建喷嘴。

## 4. 修复前复现步骤

1. 打开“创建喷嘴”。
2. 选择目标机型和可新增的喷嘴直径。
3. 点击第一页“确认”。
4. 实际：直接执行喷嘴创建，成功后关闭对话框，跳过导入预设。
5. 预期：进入“导入预设”，选择材料和工艺后点击“创建”完成保存。

禅道直接描述了步骤 1～3 及缺失第二步的现象；直接保存并关闭的执行路径来自代码分析。

## 5. 根因分析

以下结论来自本次代码检查：

- 第一页确认事件中，`m_type == 1` 分支直接调用 `create_nozzle_variant()`，成功后执行 `EndModal(wxID_OK)` 并返回，绕过 `show_page2()`。
- 构造函数跳过了喷嘴模式下的预设来源默认选择。
- `create_nozzle_variant()` 原先只保存喷嘴变体，没有读取第二页材料、工艺勾选项；仅恢复页面跳转仍不足以让导入选择生效。
- 第二页初始化每次进入都会绑定事件，需要避免往返页面后重复绑定。

## 6. 修复策略

- 第一页校验通过后统一进入第二页，最终保存仍由第二页“创建”触发。
- 喷嘴模式默认选择“基于当前打印机”，待第二页参考控件初始化后加载预设。
- 记录第一页机型、参考厂商、参考型号及喷嘴直径；来源变化时清理旧列表并重新初始化，来源不变时保留第二页选择。
- 第二页下拉框事件仅在首次初始化时绑定；模板加载使用对应页面的参考型号。
- 创建时收集实际勾选的材料、工艺，分别要求至少选择一项，并导入到目标打印机预设。
- 基于模板创建时，在工艺副本上调整喷嘴相关参数，避免取消或重试污染列表中的原始模板。
- 导入发生重名等失败时展示失败项并询问是否覆盖；导入成功后保存喷嘴变体，沿用现有喷嘴选择和界面刷新逻辑。

## 7. 代码修改摘要

- `CreatePresetsDialog.cpp`：恢复第一页到第二页的跳转；补齐默认选择、来源变化刷新、事件绑定保护及材料/工艺导入。
- `CreatePresetsDialog.hpp`：增加 `m_nozzle_import_source` 保存导入来源状态。
- 本次提交仅包含上述两个源码文件和本记录。

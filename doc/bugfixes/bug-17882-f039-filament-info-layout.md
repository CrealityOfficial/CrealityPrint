# Bug 17882 修复说明：F039 耗材信息显示混乱

- Bug ID：`17882`
- 标题：`【F039】耗材信息显示混乱`
- 禅道链接：(https://zentao.creality.com/zentao/bug-view-17882.html)
- 反馈人：康美樱
- 处理人：wangwenbin
- 分支：`release-260930`
- 影响模块：耗材丝设置、多喷嘴内联参数布局、重置按钮及次级标签颜色。
- 当前状态：修复已完成，用户已确认验证通过。

## 2. 问题现象

- 用户反馈现象：F039/K3 耗材设置中，新增的“0.2-标准”“0.4-标准”等喷嘴规格与原参数区域排列不协调，信息显得拥挤，文字层级不清晰。
- 实际结果：
  - “参数覆盖”页的“抬 Z 类型”“仅表面抬 Z”与带单位的长度、速度参数横向起点不同。
  - 流量比例、喷嘴温度、最大体积速度等多喷嘴参数与普通单值参数混排时，喷嘴规格未与普通输入框左边缘对齐。
  - 喷嘴规格原来使用默认标签颜色，视觉上偏亮，与床温“首层／其它层”的次级标签颜色不一致。
- 期望结果：保持普通输入框原有起点，多喷嘴规格从同一列开始，后续覆盖复选框和输入框向右展开；重置按钮位于内容列左侧且不遮挡文字或控件；规格文字使用相同的次级标签灰色。

```text
普通参数：参数名称  [重置区域] │ 输入框
多喷嘴项：参数名称  [重置区域] │ 0.2-标准 │ 覆盖（如有）│ 输入框
                              │ 0.4-标准 │ 覆盖（如有）│ 输入框
                              ↑ 共用内容起点
```

- 耗材：截图示例为 Hyper PLA，也展示了 CR ABS、CR PETG、HP TPU 等候选预设。
- 参数模式：高级。
- 入口：耗材丝设置。
- 模型：本问题为参数页显示问题，无需切片模型。

### 操作步骤

1. 打开对应耗材预设的“参数覆盖”页。
2. 对比长度、回抽速度与“抬 Z 类型”“仅表面抬 Z”的喷嘴规格、覆盖复选框及输入框起点。
3. 切换至“耗材丝”页，对比流量比例的喷嘴规格与直径、压力提前等普通参数框左边缘。
4. 查看喷嘴温度、最大体积速度，比较规格文字与床温“首层／其它层”的灰色。
5. 修改普通参数和某个喷嘴行，检查重置按钮的位置与点击效果。

## 4. 根因分析

### 触发条件

耗材页使用 `MultiVariantField` 展示多个喷嘴行，同时混排普通单值控件；不同参数可能包含单位后缀或覆盖复选框。

### 代码链路

```text
耗材参数页创建参数行
  → MultiVariantField 创建规格标签、覆盖复选框（如有）和子控件
  → OG_CustomCtrl::get_pos() 定位控件面板
  → OG_CustomCtrl::CtrlLine::render() 绘制参数名和重置按钮
  → draw_act_bmps() 记录对应按钮的点击矩形
```

### 问题原因

1. 原来的多喷嘴专用定位位于“单参数且无 sidetext”的分支内。无单位枚举走紧凑标签布局，有单位数值走普通布局，但多喷嘴按钮绘制统一使用紧凑标签宽度，造成定位与绘制规则不一致。
2. 普通耗材参数默认在输入框右侧绘制重置按钮，多喷嘴参数在面板左侧绘制。若仅恢复完整标签宽度，再追加按钮槽位，规格面板仍比普通输入框额外向右偏移。
3. 规格标签使用 `get_label_clr_default()`，而床温次级标签使用 `StateColor::darkModeColorFor("#6B6B6B")`，两者颜色来源不同。

这些问题属于 UI 布局和颜色规则，不涉及参数值计算或喷嘴映射数据变更。

## 5. 修复方案

### 修复思路

统一参数名称可用宽度、按钮位置和内容起点的计算。满足条件的耗材单参数行将按钮区放在原输入列左侧，普通输入框与多喷嘴面板使用同一内容起点。规格列后的控件自然向右排列。

### 修改点

- `src/slic3r/GUI/OG_CustomCtrl.hpp`
  - 增加 `FieldLayout`，集中表示标签位置、标签宽度、按钮位置和面板位置。
  - 声明 `get_field_layout()` 和 `uses_leading_action_layout()`。
- `src/slic3r/GUI/OG_CustomCtrl.cpp`
  - 删除多喷嘴紧凑标签宽度常量；多喷嘴定位不再取决于单位后缀是否为空。
  - 按图标尺寸和间距保留按钮槽位，初始化阶段也保留占位。
  - 对符合条件的耗材单参数行，保持原内容起点，从其左侧预留按钮区，并扣减标签可用宽度。
  - 定位、标签绘制和重置按钮绘制共用布局结果；长名称的行高按可用标签宽度计算。
  - 普通行在左侧绘制按钮后跳过原右侧按钮绘制；点击矩形仍由 `draw_act_bmps()` 根据实际绘制位置生成。
  - 前置按钮布局限定于耗材单参数行，排除无标签、整行宽度控件、附加控件、自定义编辑入口等特殊布局。床温的一行多参数继续走原逻辑。
- `src/slic3r/GUI/Field.cpp`
  - 规格标签创建和主题切换均使用 `StateColor::darkModeColorFor("#6B6B6B")`，与床温“首层／其它层”使用相同颜色规则。
  - 最终代码不保留白色与背景色混合的调暗实现，不通过禁用控件实现灰色。

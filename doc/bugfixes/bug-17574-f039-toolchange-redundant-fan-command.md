# Bug 17574：F039 切换耗材时输出旧耗材风扇指令

## 1. 基本信息

- Bug ID：`17574`
- 标题：`【F039】切换耗材时，存在多余的上一个耗材丝风扇指令`
- 禅道链接：未提供
- 反馈人：康美樱
- 处理人：`wangwenbin`
- 分支：`release-260830`
- 影响模块：F039 换料 G-code、风扇冷却后处理

## 2. 问题现象

- 用户反馈现象：F039 多耗材切片后，在一次耗材切换位置连续出现旧耗材和新耗材的两组风扇指令。
- 实际结果：例如 TPU 切换到 PLA 时输出：

```gcode
M106 P2 S109
M106 S196
M106 S168
M106 P2 S124
```

  前两条是旧 TPU 的辅助风扇和全局模型风扇状态，后两条才是新 PLA 的目标状态。
- 期望结果：换料前不再恢复即将停用的旧耗材风扇状态，只输出新耗材需要的风扇状态。

## 3. 复现步骤

- 前置条件：
  - 机型：F039。
  - 使用两种及以上风扇参数不同的耗材，例如 TPU、PLA、ABS、PETG。
  - 配置不包含 `Tn` 的自定义换料脚本，由切片器在脚本后生成工具切换指令。
- 操作步骤：
  1. 为模型分配多种耗材并启用换料流程。
  2. 完成切片并导出 G-code。
  3. 定位 `; CP TOOLCHANGE START`，检查自定义换料脚本结束到 `Tn` 之间的 `M106` 指令。
- 复现结果：先输出旧耗材风扇状态，随后又输出新耗材风扇状态，形成冗余指令。
- 复现概率：满足上述配置时稳定复现。

## 4. 根因分析

- 触发条件：自定义换料脚本存在，但脚本自身不包含目标工具的 `Tn`；工具切换由切片器在脚本结束后补充。
- 代码链路：
  - F039 擦拭塔路径：`WipeTowerIntegration::append_tcr_creality()` / `append_tcr_creality_cfs()`。
  - 换料处理：`GCode::set_extruder_new()`。
  - 通用换料路径：`GCode::set_extruder()`。
  - 风扇后处理：`GCodeEditor::parse_layer_gcode()` → `GCodeEditor::write_layer_gcode()`。
- 问题原因：
  - 原逻辑在自定义脚本结束后无条件插入 `;_FORCE_RESUME_FAN_SPEED`，用于防止自定义脚本修改风扇后没有恢复。
  - 当脚本不包含 `Tn` 时，风扇后处理器此时仍认为旧耗材处于激活状态，因此先恢复旧耗材风扇。
  - 随后的 `Tn` 又触发新耗材风扇计算，最终连续生成旧、新两组 `M106`。
  - 不带工具编号的 `M106` 控制全局模型风扇，恢复旧耗材状态没有实际保留价值，还会造成瞬时错误状态和冗余 G-code。

## 5. 修复方案

- 修复思路：根据自定义脚本是否已执行目标 `Tn`，选择不同的风扇恢复时机。
  - 自定义脚本包含 `Tn`：工具已切换，脚本结束后继续使用原有恢复逻辑，恢复当前新耗材风扇。
  - 自定义脚本不包含 `Tn`：不立即恢复旧耗材风扇，记录延迟恢复标记；处理切片器生成的 `Tn` 时，直接强制输出新耗材目标风扇。
  - 骨架冲刷已提前登记工具切换，继续保留原恢复逻辑。
- 修改点：
  - `src/libslic3r/GCode.cpp`
    - 在 `set_extruder_new()` 和 `set_extruder()` 中缓存自定义脚本是否包含目标 `Tn`。
    - 根据工具是否已经切换，输出 `;_FORCE_RESUME_FAN_SPEED` 或新的 `;_FORCE_FAN_SPEED_ON_TOOL_CHANGE` 标记。
  - `src/libslic3r/GCode/CoolingBuffer.hpp`
    - 新增 `TYPE_FORCE_FAN_ON_TOOL_CHANGE` 风扇事件类型。
  - `src/libslic3r/GCode/CoolingBuffer.cpp`
    - 解析新的延迟恢复标记。
    - 在下一个工具切换事件更新耗材后，强制输出新耗材的模型风扇和辅助风扇目标值。
    - 特殊区域控制辅助风扇时，重新应用该区域当前持有的状态，避免被普通耗材参数覆盖。

## 7. 风险与回退

- 可能风险：延迟标记未被正确消费时，换料后的模型风扇或辅助风扇速度可能不正确，并持续到下一条风扇调速指令。
- 风险影响范围：
  - 主要影响换料附近的冷却效果，可能造成 PLA 悬垂质量下降，或 TPU、PETG 等材料因风扇过高导致层间粘接下降。
  - 不修改喷嘴温度、运动、挤出量和工具选择逻辑，预期不会造成设备损伤；整体风险偏低，打印质量风险为中低。
  - 新逻辑仅由新增内部标记触发，未使用该标记的普通冷却流程不受影响。
- 回退方案：回退 `GCode.cpp`、`CoolingBuffer.cpp` 和 `CoolingBuffer.hpp` 中本次新增的延迟风扇恢复逻辑，恢复原有 `;_FORCE_RESUME_FAN_SPEED` 行为。

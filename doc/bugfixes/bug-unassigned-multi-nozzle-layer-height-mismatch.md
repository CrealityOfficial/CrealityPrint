# 多喷嘴口径参数错位导致擦拭塔层高误判修复说明

- Bug ID：未提供

- 禅道链接：未提供
- 反馈人：未提供

- 影响模块：K3 多喷嘴口径变体、3MF 参数恢复、Printer/Process/Filament 参数页、切片层高约束、擦拭塔切片校验

## 2. 问题现象

### 自测现象

- K3 的 4 个物理喷嘴实际均为 `0.4 mm`。
- 导入 4 个模型并分别指定 `T0/T1/T2/T3` 后，界面却显示为：
  - P1：`0.2 mm`
  - P2：`0.4 mm`
  - P3：`0.6 mm`
  - P4：`0.4 mm`
- 开启擦拭塔切片时提示：`擦拭塔要求各个对象拥有同样的层高`，导致无法正常切片。

### 实际结果

- 3MF 中保存的物理挤出机、喷嘴口径变体和参数行没有被完整、原子地恢复。
- 逻辑耗材 `Tn`、物理喷嘴 `Pn` 和喷嘴变体参数行发生错位。
- 不同对象生成了不一致的派生层高约束，最终被擦拭塔的 `equal_layering()` 校验判为不兼容。

### 期望结果

- 四路均选择 `0.4 mm` 时，界面、3MF、切片配置和派生层高范围均保持为四路 `0.4 mm`。
- `Tn` 必须先通过 `filament_map[Tn]` 映射到物理喷嘴，再读取该喷嘴的口径、最小层高和最大层高。
- 多个对象的真实层高条件一致时，不应因参数索引错位误报擦拭塔层高不一致。
- 真正不兼容的喷嘴组合、Process 或损坏的 selector 数组应明确失败，不能猜测参数行或提交半套状态。

## 3. 复现步骤

### 前置条件

- 机型：Creality K3，4 个物理挤出机。
- 四路喷嘴实际配置：`0.4/0.4/0.4/0.4 mm`。
- 模型：4 个对象，分别使用 `T0/T1/T2/T3`。
- 打印方式：按层打印并启用擦拭塔。
- 入口：导入或重新打开包含多喷嘴变体配置的 3MF 项目。

### 操作步骤

1. 选择 K3 打印机预设，并确认四路喷嘴均为 `0.4 mm`。
2. 导入 4 个模型，分别为对象指定耗材 `T0/T1/T2/T3`。
3. 保存 3MF，关闭后重新打开，或直接导入已有多色 3MF。
4. 检查侧边栏四路喷嘴口径和 Printer/Process/Filament 参数页。
5. 启用擦拭塔并执行切片。

### 复现结果

- 四路喷嘴可能恢复成 `0.2/0.4/0.6/0.4 mm` 等错误组合。
- 参数页可能读取其他物理挤出机或其他口径的参数行。
- 切片阶段误报对象层高不一致。

### 复现概率

- 本次反馈样例可复现。
- 不同旧项目、selector 完整性和参数行排列方式下的总体概率待补充。

## 4. 根因分析

### 触发条件

- 项目包含多路物理挤出机和喷嘴口径变体。
- 3MF 使用紧凑参数保存，重新打开时需要从完整预设恢复各物理挤出机的目标参数行。
- 多个对象分别使用不同逻辑耗材，并在切片阶段参与擦拭塔层高一致性校验。

### 代码链路

```text
3MF 项目参数
  -> Preset 参数行恢复
  -> DynamicPrintConfig::get_index_for_extruder()
  -> DynamicPrintConfig::select_extruder_variant_values()
  -> PresetBundle::full_fff_config()
  -> SlicingParameters::create_from_config()
  -> Print::validate()
  -> equal_layering()
```

### 问题原因

1. 3MF 参数行恢复使用了不完整身份。

   - Process 参数原来没有强制比较物理挤出机 ID。
   - `nozzle_variant` 缺失或长度错误时，旧逻辑会把口径条件当成可忽略条件。
   - 相同热端类型下，E1～E4 和 0.2/0.4/0.6/0.8 参数行可能命中第一条相似记录，造成跨挤出机、跨口径串行。

2. selector 平行数组错误时仍继续匹配。

   - `printer_extruder_id`、`printer_extruder_variant`、`printer_nozzle_variant` 等数组本应逐行对应。
   - 旧逻辑未严格区分“旧格式缺少字段”和“字段存在但数组错长”，损坏数据可能被当成通配条件继续使用。

3. 变体参数被分两次压缩，破坏了索引语义。

   - `PresetBundle::full_fff_config()` 原来先压缩普通 Printer 变体参数，再单独压缩 `min_layer_height/max_layer_height`。
   - 第一次压缩后 selector 数组已变为紧凑的四路结果；第二次再使用它们选择原始层高行时，源数组与 selector 已不再处于同一行空间。
   - 因此层高参数可能回退到错误行或第 0 行。

4. 切片阶段混用了逻辑耗材索引和物理喷嘴索引。

   - `object_extruders()` 返回的是从 0 开始的逻辑耗材 `Tn`。
   - 喷嘴口径、最小层高和最大层高属于物理喷嘴参数，读取前必须执行 `Tn -> filament_map[Tn] -> Pn`。
   - 旧辅助函数还对传入索引执行 `-1`，使 `T0` 出现下溢/回退，并使其他工具产生偏一位读取。

5. 支撑耗材的 `0` 语义依赖隐式下溢。

   - `support_filament=0` 表示自动或跟随当前对象耗材，不是物理喷嘴 0。
   - 旧逻辑通过无符号减一后回退到首项，不能正确处理包含多个活动耗材的对象。

上述错误最终使各对象的 `SlicingParameters` 不一致，擦拭塔校验本身只是发现了派生结果差异，并不是根因。

## 5. 修复方案

### 修复思路

- 统一参数索引语义：`Tn` 始终表示逻辑耗材，物理喷嘴参数统一先通过 `filament_map` 解析。
- 使用“物理挤出机 ID + 热端类型 + 喷嘴口径”完整身份恢复参数行。
- 所有属于同一变体行的 selector 和参数向量必须在同一次选择中原子压缩。
- selector 存在但长度错误时立即失败并记录 warning，不再降级成通配匹配。
- UI 补行只修改 edited preset，并从同口径 reference preset 获取默认值。

### 修改点

- `src/libslic3r/Preset.cpp`
  - Process 恢复加入物理挤出机 ID。
  - 强制校验喷嘴 selector 和参数向量覆盖范围。
  - 防止同一个项目参数行被重复恢复到多个目标行。
  - 无法唯一匹配时回退 source preset，不猜测参数。

- `src/libslic3r/PrintConfig.cpp`
  - 严格校验 selector 平行数组的长度和空值语义。
  - 区分旧格式缺少 selector 与损坏格式 selector 错长。
  - 避免空 `extruder_type` 和错位数组访问。

- `src/slic3r/GUI/Tab.cpp`
  - 参数页缺少目标口径行时，优先从同口径 reference config 复制。
  - UI 刷新和自动补行不再修改 selected/source preset。
  - 保证 Dirty、Undo 和恢复默认值仍以未污染的 source preset 为基线。

- `src/slic3r/GUI/SiderBar.cpp`
  - 喷嘴切换前先检查公共层高和兼容 Process。
  - 找不到兼容 Process 时立即返回，不写入新的喷嘴变体状态。
  - Process 切换失败时恢复旧状态，避免项目只提交一半配置。

- `src/libslic3r/PresetBundle.cpp`
  - 将 `min_layer_height/max_layer_height` 加入同一组 Printer 变体参数。
  - selector、层高和其他单值变体参数在一次调用中按同一源行原子选择。

- `src/libslic3r/Slicing.cpp`
  - 新增逻辑耗材到物理喷嘴的统一解析路径。
  - 使用映射后的物理喷嘴读取 `nozzle_diameter/min_layer_height/max_layer_height`。
  - 支撑耗材显式指定时按指定 `Tn` 解析；配置为 `0` 时按对象活动耗材集合计算约束。
  - 多个活动喷嘴共同参与时，最小层高取各喷嘴下限的最大值，最大层高取各喷嘴上限的最小值。

## 7. 风险与回退

### 可能风险

- 旧 3MF 的 selector 字段不完整，需要确认 legacy fallback 不会误伤可恢复项目。
- 参数行由宽表压缩为当前四路配置时，新增键必须与 selector 保持同一次原子选择。
- 支撑耗材 `0` 参与多个活动耗材时，公共层高可能比旧版本更严格，这是正确约束变化，但需要回归 Process 过滤和提示文案。
- 异径擦拭塔仍存在单一线宽、单一喷嘴等历史假设；本修复解决参数错位和假层高冲突，不代表已经完成异径擦拭塔的几何与出料验证。

### 风险影响范围

- K3 多物理挤出机、多喷嘴口径变体项目。
- 3MF 保存/恢复、参数页切换、Process 过滤、支撑层高约束和擦拭塔校验。
- 不涉及发送页面、设备协议、CFS 槽位匹配和真机控制。

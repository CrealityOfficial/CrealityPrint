# K3 多口径起始排料按物理喷嘴适配说明

## 1. 基本信息

- Bug ID：未提供
- 标题：K3 起始排料和擦嘴参数未按实际物理喷嘴口径适配
- 禅道链接：未提供
- 反馈人：未提供
- 处理人：wangwenbin
- 分支：`feature/f039_group`
- 影响模块：G-code 占位符、K3 机型起始 G-code

## 2. 问题现象

K3 支持把逻辑耗材 `Tn` 映射到不同编号、不同口径的物理喷嘴 `Pn`。原起始 G-code 在选择首个非支撑耗材后，排料线仍固定使用 0.4 mm 喷嘴的高度、挤出量、速度截面和负 Z 擦嘴参数。

此外，起始排料实际执行者是 `initial_no_support_extruder`，但部分速度参数仍来自 `initial_extruder`。当两者不同，或者 `Tn` 没有映射到同编号的 `Pn` 时，实际喷嘴与参数来源可能不一致。

期望行为是：

```text
首个非支撑逻辑耗材 Tn
        ↓ filament_map[Tn]
实际物理喷嘴 Pn
        ↓ nozzle_diameter[Pn]
选择 0.2 / 0.4 / 0.6 / 0.8 起始排料分支
```

## 3. 复现步骤

### 前置条件

- 机型选择 K3。
- 启用多喷嘴耗材映射。
- 至少配置一种非 0.4 mm 物理喷嘴，或者让逻辑耗材映射到非同编号物理喷嘴。

### 操作步骤

1. 创建包含普通模型耗材的任务。
2. 将首个非支撑逻辑耗材映射到 0.2、0.6 或 0.8 mm 物理喷嘴。
3. 切片并导出 G-code。
4. 检查 `M8200 L`、`Tn` 后面的起始排料和擦嘴段。

### 原复现结果

- 排料高度固定为 `Z0.2`。
- 主排料量固定为 `E15`。
- 擦嘴段固定为 `E0.3742` 和 `0.3*0.5` 速度截面。
- 负 Z 擦嘴固定为 `Z-0.3`。
- 主排料速度错误使用 `filament_max_volumetric_speed[initial_extruder]`。

复现概率：满足上述映射条件时必现；普通 `T0 → P0` 且喷嘴均为 0.4 mm 时不易观察。

## 4. 根因分析

### 触发条件

- `initial_extruder != initial_no_support_extruder`；或者
- `filament_map[Tn]` 指向非同编号物理喷嘴；或者
- 首个非支撑耗材对应的物理喷嘴不是 0.4 mm。

### 代码链路

```text
ToolOrdering 计算 initial_non_support_extruder_id
        ↓
GCode::_do_export 注册起始 G-code 占位符
        ↓
filament_map 将逻辑耗材映射为物理喷嘴
        ↓
K3 machine_start_gcode 生成排料线和擦嘴动作
```

原逻辑只有首个逻辑耗材占位符，没有直接暴露“首个非支撑耗材映射到的物理喷嘴”。模板因此无法按实际喷嘴口径选择参数。同时，`outer_wall_volumetric_speed` 的外墙速度索引错误使用了 `initial_extruder_id`，与同一计算中的非支撑耗材 MVS、物理喷嘴直径不一致。

## 5. 修复方案

### 修复边界

- FLUSH 冲刷段完全不修改。
- 模型自动线宽逻辑不修改，仍由用户手动开启。
- 只调整 K3 的起始排料和压力擦嘴段。

### 修改点

1. `src/libslic3r/GCode.cpp`
   - 新增零基占位符 `initial_no_support_physical_nozzle_id`。
   - 通过 `get_physical_nozzle_index(m_config, initial_non_support_extruder_id)` 得到实际物理喷嘴。
   - `outer_wall_volumetric_speed` 的喷嘴速度索引统一改用 `initial_non_support_extruder_id` 的物理映射。

2. `src/libslic3r/PrintConfig.cpp`
   - 注册新占位符的名称、类型和说明。

3. `resources/profiles/Creality/machine/Creality K3 0.4 nozzle.json`
   - 使用 `nozzle_diameter[initial_no_support_physical_nozzle_id]` 按实际口径分支。
   - 主排料 MVS 改用 `filament_max_volumetric_speed[initial_no_support_extruder]`。
   - 导出诊断注释，直接显示逻辑耗材、物理喷嘴和喷嘴口径。

### 参数职责

| 参数                            | 职责                            | 索引依据                               |
| ------------------------------- | ------------------------------- | -------------------------------------- |
| `prime_e`                       | 起始主排料的耗材长度            | 物理喷嘴口径分支及实机标定             |
| `prime_speed_area`              | 把材料 MVS 换算成主排料移动速度 | 物理喷嘴口径                           |
| `wipe_e`                        | 每段压力擦嘴线的耗材长度        | 物理喷嘴口径                           |
| `wipe_speed_area`               | 把体积速度换算成擦嘴移动速度    | 物理喷嘴口径                           |
| `press_z`                       | 压力擦嘴的相对下压量            | 物理喷嘴口径及机构标定                 |
| `filament_max_volumetric_speed` | 材料允许的最大体积速度          | 逻辑耗材 `initial_no_support_extruder` |

### 当前分支参数

| 物理喷嘴 | 排料 Z | `prime_e` | `prime_speed_area` | `wipe_e` | `wipe_speed_area` | `press_z` | 状态                       |
| -------- | -----: | --------: | -----------------: | -------: | ----------------: | --------: | -------------------------- |
| 0.2 mm   |    0.1 |      3.75 |              0.075 |  0.09355 |       `0.15*0.25` |      -0.2 | 几何比例初值，优先实机标定 |
| 0.4 mm   |    0.2 |        15 |                0.3 |   0.3742 |         `0.3*0.5` |      -0.3 | 保持原行为                 |
| 0.6 mm   |    0.3 |     33.75 |              0.675 |  0.84195 |       `0.45*0.75` |      -0.4 | 几何比例初值，待实机标定   |
| 0.8 mm   |    0.4 |        60 |                1.2 |   1.4968 |         `0.6*1.0` |      -0.5 | 几何比例初值，待实机标定   |

非 0.4 mm 参数按 `(喷嘴口径 / 0.4)^2` 对排料量和截面积做初始缩放。压力擦嘴不按口径比例缩放，而是根据各分支的起始排料 Z 计算相对下压量，确保最终绝对位置统一为 `Z=-0.1`。除 0.4 mm 外，其余排料参数仍是便于开始实机标定的初值，不应视为已经完成打印质量认证。

未知口径不会无声套用 0.4 mm 参数，而是跳过压力排料和负 Z 擦嘴，避免喷嘴碰撞。

## 6. 验证清单

### 必测场景

- `T0 → P0，P0=0.4`：确认 0.4 参数保持原值。
- `T2 → P2，P2=0.2`：确认选择 0.2 分支，MVS 使用逻辑耗材 2。
- `T2 → P3，P3=0.2`：确认按照 `P3` 的口径进入 0.2 分支，而不是按照逻辑编号 2 判断。
- 分别导出 0.6 和 0.8 mm 起始 G-code，确认分支及参数完整展开。

### 边界场景

- `initial_extruder != initial_no_support_extruder`。
- 逻辑耗材编号与物理喷嘴编号不一致。
- 未支持的喷嘴口径进入安全兜底，不输出负 Z 擦嘴动作。
- 导出 G-code 不包含未解析的占位符或 `{if}` 语句。

### 反向场景

- 三段 FLUSH 的内容和固定冲刷量保持不变。
- 不开启自动线宽时，模型线宽行为保持原逻辑。
- 普通单口径 0.4 mm、同编号映射任务的起始排料参数保持不变。

### 当前验证结果

- 已完成源码静态检查。
- 已完成 K3 JSON 解析检查。
- 已确认 FLUSH 段与修改前一致。
- 已确认模板包含四种口径分支及未知口径兜底。
- 已完成 0.2 mm、0.4 mm 实际切片导出检查；物理喷嘴口径分支、排料参数和压力擦嘴最终 `Z=-0.1` 均符合当前设计。

## 7. 风险与回退

### 可能风险

- 0.2、0.6、0.8 mm 当前值是几何比例初值，实际热端背压、喷嘴尖端结构和擦嘴机构不一定按口径平方或线性变化。
- 负 Z 动作属于机械接触参数，必须重点观察喷嘴、热床和擦嘴区域的受力。
- 不同材料 MVS 差异可能改变实际排料速度，需要覆盖 PLA、PETG、TPU 等典型材料。

### 风险影响范围

仅影响 K3 起始排料和压力擦嘴段，不影响 FLUSH、模型路径、自动线宽和打印中的换色冲刷逻辑。

### 回退方案

- 可单独回退 K3 机型预设中的口径分支，恢复原 0.4 mm 起始段。
- 可同时移除新占位符和体积速度索引修正，恢复修改前行为。

## 8. 备注

- BambuStudio 使用独立的 `initial_no_support_hotend` 表达首个非支撑耗材对应的物理热端，本次实现沿用当前工程的 `physical_nozzle_id` 命名体系。
- 建议实机标定顺序：0.2 mm → 0.6 mm → 0.8 mm。
- 0.2 mm 首轮重点观察出料是否稳定、是否堵头、擦嘴是否过压以及首层起线是否完整。

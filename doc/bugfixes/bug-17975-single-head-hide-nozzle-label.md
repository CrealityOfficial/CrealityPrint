# Bug 17975：单规格隐藏喷嘴标签及悬垂、桥接速度分组修复

## 1. 基本信息

- Bug ID：`17975`
- 标题：`【急】【F039】单头机型不需要显示0.4喷嘴`
- 禅道链接：未提供
- 反馈人：康美樱
- 处理人：`wangwenbin`
- 分支：`release-260930`
- 更新日期：`2026-09-16`
- 影响模块：工艺悬垂速度、桥接速度、耗材参数覆盖的标签，以及内部桥接速度的配置存储和切片取值。
- 本次补充要求：喷嘴名放在左侧参数名称上方；恢复一个名称对应多个值的列表；桥接外部和内部速度均按喷嘴独立。

## 2. 问题现象

- 用户反馈现象：单头机型只有一种有效喷嘴规格时，工艺参数的悬垂速度和耗材丝设置的参数覆盖仍显示“0.4-标准”等喷嘴规格标签。
- 实际结果：单规格场景出现没有区分作用的喷嘴标签；切换单规格/多规格或悬垂参数显隐状态后，参数区还可能保留旧高度，导致大面积空白、控件位置下移或标题看似重复。
- 期望结果：只有一种有效喷嘴规格时隐藏喷嘴标签并取消对应占位；存在两种及以上有效规格时继续显示标签，用于区分各规格参数。
- 后续截图反馈：多规格悬垂速度被拆成左侧百分比行，“悬垂速度”名称消失，喷嘴名挤在首行输入框前；桥接也显示为分开的“外部／内部”。
- 最终期望：多规格名称位于左侧“悬垂速度”“桥接”名称上方，与名称左对齐；输入框纵向排列，百分比或外部／内部位于输入框右侧。每个喷嘴分别修改、保存和恢复桥接的两个速度。

## 3. 复现步骤

### 前置条件

- 使用 F039 单头机型。
- 当前有效喷嘴规格只有一种，例如 `0.4-标准`。
- 已加载对应机型、工艺和耗材预设。

### 操作步骤

1. 进入“工艺 → 速度 → 悬垂速度”。
2. 查看 10%、25%、50%、75% 等悬垂速度参数行。
3. 打开“耗材丝设置 → 参数覆盖”。
4. 查看回抽等支持按喷嘴规格配置的参数行。
5. 增加另一种有效喷嘴规格（例如 `0.8-标准`），返回“工艺 → 速度”观察参数区布局。
6. 使用 K3/F039 的 `0.2-标准`、`0.4-标准` 组合，检查悬垂速度及桥接的组名称、子项和喷嘴标题位置。
7. 分别修改各喷嘴的桥接内部速度，检查能否独立保存；切换经典模式，检查悬垂 `100%` 项。

### 复现结果

- 悬垂速度参数前显示 `0.4-标准` 标签。
- 耗材参数覆盖的每个独立参数前显示 `0.4-标准` 标签。
- 单规格与多规格布局切换后，动态参数行可能误入普通布局，或参数区沿用切换前的旧高度，出现异常空白和控件错位。

### 复现概率

- 满足单一有效喷嘴规格条件时稳定复现。
- 上述概率沿用原始记录；布局问题依据用户截图。补回旧分组整体隐藏后，用户确认当前界面效果正常；完整复现工程未提供。

## 4. 根因分析

### 触发条件

- 当前喷嘴布局按“喷嘴口径 + 喷嘴类型”去重后只有一组。
- 参数属于耗材喷嘴规格参数，或属于经过转置生成的悬垂速度参数行。

### 代码链路

- `Tab.cpp::get_multi_variant_input_layout()` 根据当前有效喷嘴规格生成参数布局。
- `MultiVariantField::refresh_layout()` 创建耗材参数覆盖控件并决定是否显示规格标签。
- `ConfigOptionsGroup::refresh_overhang_layout()` 按喷嘴规格生成悬垂速度参数行。
- `OG_CustomCtrl::uses_leading_action_layout()` 决定动态参数行采用普通布局还是前置操作按钮布局。
- `OG_CustomCtrl::update_visibility()` 根据当前可见行更新控件最小尺寸。
- `Page::update_visibility()` 汇总页面内各参数组的显隐状态。

### 问题原因

1. 耗材参数覆盖原判断除 `layout.size() > 1` 外，还对耗材规格参数强制显示标签，导致单规格场景也显示 `0.4-标准`。
2. 悬垂速度原逻辑无条件写入 `field_prefix`，单规格场景同样显示喷嘴标签。
3. `field_prefix` 同时承担“显示标签文字”和“选择专用布局”两个职责。仅把单规格的 `field_prefix` 清空，会让悬垂速度退出专用布局，继而产生空白和控件错位。
4. 动态显隐更新只调用 `SetMinSize()`，页面没有在所有参数组更新完成后立即重新布局。日志显示多规格场景的可见内容高度为 `531`，而控件实际高度仍为切换前的 `689`，多出的旧高度被显示为空白区域。
5. 悬垂速度按百分比拆成单参数行，丢失原有组名称。前缀、首行标签控制和后续强制排版标记均服务于这套旧布局，本次改用原生多选项列表后不再需要。
6. 内部桥接速度原为 `ConfigOptionFloatOrPercent`，未加入 `print_options_with_variant`，所以只修改界面不能实现独立存储。本次按用户最终要求扩展为喷嘴独立参数。

上述第 1～4 项为历史问题和诊断记录。当前内部速度通过公共工艺参数集合进入 `PresetBundle.cpp` 的规格源行选择；`GCode.cpp` 已通过 `get_abs_value_at("internal_bridge_speed", cur_extruder_index())` 按对应索引读取，百分比基准仍为该喷嘴的外部速度。

## 5. 修复方案

### 修复思路

- 统一规则：有效喷嘴规格只有一组时隐藏标签；存在多组时显示标签。
- 悬垂和桥接复用原生多选项纵向列表，保留参数名称、逐项输入及恢复能力；喷嘴名放在左侧名称上方，不增加可点击页签。
- 删除旧前缀、首行名称开关及强制排版标记，保留已有公共页面刷新和旧控件生命周期防护。
- 重建前调用 `old_sizer->ShowItems(false)`，同时隐藏旧标题和内容，避免窗口延迟销毁期间与新分组共存，造成空白或重复标题。
- 在页面完成全部参数组的显隐计算后统一执行布局和滚动区域尺寸更新，使控件实际高度与新的最小高度同步。
- 保持公共喷嘴规格去重和映射规则；内部桥接速度改为按喷嘴独立存储的百分比／绝对值数组，默认值仍为 `150%`，其他参数语义不变。

### 修改点

- `src/slic3r/GUI/Field.cpp/.hpp`
  - 提取 `show_variant_labels()`，普通独立参数与组合列表共用单规格隐藏、多规格显示规则。
- `src/slic3r/GUI/OptionsGroup.cpp`
  - 每个喷嘴生成完整悬垂列表和桥接外部／内部列表；喷嘴名加入左侧参数名称上方。
  - 经典模式决定是否创建 `100%` 项；重建后重载当前配置，悬垂显隐按整组处理。
  - `clear()` 前整体隐藏旧分组，补回 stash 中已定位的延迟销毁显示修复。
- `src/slic3r/GUI/OptionsGroup.hpp`
  - 删除 `field_prefix`、`show_field_prefix_name`、`force_leading_action_layout`；记录布局初始化和经典模式状态。
- `src/slic3r/GUI/OG_CustomCtrl.cpp`
  - 删除旧前缀占位和专用绘制；多值列表按参数名称单行字号计算输入行高度，避免标题放大每行高度。
- `src/slic3r/GUI/Tab.cpp`
  - 保留 `97df2c1ea` 中 Windows 页面显隐后执行 `Layout()`、`FitInside()` 的修复；本次没有新增该文件差异。
- `src/libslic3r/PrintConfig.cpp/.hpp`
  - `internal_bridge_speed` 改为 `ConfigOptionFloatsOrPercentsNullable`，加入 `print_options_with_variant`，沿用对应喷嘴 `bridge_speed` 的百分比基准。
- `src/slic3r/GUI/AnalyticsDataUploadManager.cpp`
  - 内部速度统计改用向量首值读取，与同类参数一致。
- `tests/libslic3r/test_config.cpp`、`tests/libslic3r/test_placeholder_parser.cpp`
  - 补充独立百分比、绝对值、旧单值读取、多值序列化、规格源行选择及占位符映射用例；尚未运行。

最终显示规则：

| 当前有效规格 | 标签 | 标签占位 | 参数布局 |
| --- | --- | --- | --- |
| 单个 `0.4-标准` | 隐藏 | 不保留 | 原生名称＋纵向值列表 |
| 多个喷头但规格均为 `0.4-标准` | 隐藏 | 不保留 | 原生名称＋纵向值列表 |
| `0.4-标准` + `0.6-标准` | 显示在左侧参数名称上方 | 与名称左对齐 | 每种规格一组列表 |
| `0.4-标准` + `0.4-高流量` | 显示在左侧参数名称上方 | 与名称左对齐 | 每种规格一组列表 |

桥接的外部和内部均绑定同一喷嘴源索引，不保留共用内部速度入口。旧预设的单个值沿用向量单值兼容读取，运行兼容验证待完成。

数值验收示例（非预设调参）：A 外部 `30 mm/s`、内部 `150%`，内部为 `45 mm/s`；B 外部 `60 mm/s`、内部 `120%`，内部为 `72 mm/s`。将 B 内部改为绝对值 `80 mm/s`，A 应仍为 `45 mm/s`。

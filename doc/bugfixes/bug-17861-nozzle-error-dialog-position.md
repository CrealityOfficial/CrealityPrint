# Bug 17861 修复说明：F039 全部选择 0.2 口径时切片报错弹窗不居中

## 1. 基本信息

- Bug ID：17861
- 标题：【F039】口径全部选择0.2。切片后报错弹窗位置不居中
- 禅道链接：(https://zentao.creality.com/zentao/bug-view-17861.html)
- 反馈人：康美樱
- 处理人：wangwenbin
- 分支：`release-260930`
- 影响模块：F039/K3 耗材分组、切片前喷嘴映射校验提示

## 2. 问题现象

- 用户反馈：喷嘴口径全部选择 0.2，点击切片后，报错弹窗位置不居中。
- 截图显示：机型为 Creality K3，四个喷嘴均为 `0.2-标准`；工艺为 `0.20mm Standard @Creality K3`，层高、首层层高均显示为 0.2。
- 实际结果：标题为“耗材分组”、内容为“当前工艺层高与所有已配置喷嘴均不兼容。”的警告弹窗出现在右上角耗材区域。
- 期望结果：该警告相对应用主窗口居中显示，用户可清晰看到并确认提示。
- “切片后”指点击切片后出现提示；从代码链路看，该提示属于切片前映射校验失败，不代表切片已完成。

## 3. 复现步骤

### 前置条件

- 机型：F039 / Creality K3，启用多喷嘴耗材映射功能。
- 喷嘴：四个喷嘴口径全部选择 `0.2-标准`。
- 工艺：按截图选择 `0.20mm Standard @Creality K3`，层高和首层层高为 0.2，使当前工艺与所有配置喷嘴不兼容。
- 模型及耗材：盘内有模型并配置耗材；截图可见多个立方体和 Hyper PLA。原始工程、完整耗材配置未提供。

### 操作步骤

1. 打开准备页面，选择上述机型并添加模型、配置耗材。
2. 将四个喷嘴口径全部设为 `0.2-标准`，保持上述工艺设置。
3. 点击“切片单盘”。
4. 观察“耗材分组”警告弹窗的位置。

- 复现结果：修复前弹窗位于右上角耗材区域，未相对主窗口居中。
- 复现概率：未提供；本次依据用户截图及源码分析，未进行本地 GUI 复现。

## 4. 根因分析

### 触发条件

当前工艺层高与所有配置喷嘴均不兼容，自动映射解析返回错误，进入耗材分组的警告提示分支。

### 代码链路（关键函数/关键判断）

1. `MainFrame::slice_plate()` 进入切片前耗材映射准备流程。
2. `FilamentPanel::prepare_filament_nozzle_mapping_for_slice()` 调用 `show_filament_grouping_dialog()`。
3. `resolve_effective_filament_map()` 的自动映射路径发现没有兼容喷嘴，返回上述层高不兼容提示（错误文本位于 `src/libslic3r/PrintConfig.cpp`）。
4. `show_filament_grouping_dialog()` 原来通过 `MessageDialog(this, ...)` 显示警告，此处 `this` 是右上方的 `FilamentPanel`。
5. `src/slic3r/GUI/MsgDialog.cpp` 中，`MessageDialog` 构造时调用 `finalize()`，执行 `Fit()` 和 `CenterOnParent()`。

### 问题原因

弹窗已有居中逻辑，但父窗口选成了耗材面板，因此它相对右上方耗材区域居中，而不是相对应用主窗口居中。耗材区域的位置和尺寸也会影响弹窗位置。

## 5. 修复方案

### 修复思路

统一切片前及分组窗口打开前的校验提示所使用的父窗口，优先取应用主窗口，沿用公共弹窗的 `CenterOnParent()` 实现。

### 修改点（文件 + 关键逻辑）

修改文件：`src/slic3r/GUI/FilamentPanel.cpp`。

- `apply_current_filament_nozzle_mapping()`：增加 `dialog_parent`，主窗口存在时使用 `wxGetApp().mainframe`，否则回退到当前面板。无可用喷嘴、映射完整性校验失败、映射解析失败的三处警告均使用该父窗口；混色耗材喷嘴口径校验也传入该父窗口。
- `show_filament_grouping_dialog()`：将原有分组对话框的 `dialog_parent` 选择逻辑提前到校验之前，供无可用喷嘴、保存映射无效、自动映射失败的三处警告及无使用耗材时的混色校验复用。
- 分组对话框内部的手动映射、混色耗材校验仍传入 `&dialog`，保持相对当前分组窗口居中。
- 公共 `MessageDialog`、兼容性判断、映射算法和错误文本未修改。

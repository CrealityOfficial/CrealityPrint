# Bug 17968：不兼容喷嘴补充层高范围提示

## 基本信息

- 禅道：[Bug #17968](https://zentao.creality.com/zentao/bug-view-17968.html)
- 标题：【多口径】【bug类需求】不兼容预设新增文案提示
- 计划：CP 7.3.0 Beta
- 涉及界面：喷嘴耗材设置弹窗

## 问题与预期

当工艺预设的层高或首层层高超出某个喷嘴支持的范围时，该喷嘴会被判定为与当前预设不兼容。原界面仅在喷嘴卡片标题处标红、显示“不兼容的预设”，并提供悬浮提示；卡片内容为空时仍显示“无耗材”。用户无法直接看到支持范围与当前预设数值。

禅道截图中的例子为：喷嘴 2 使用 0.2 mm 口径，支持层高为 0.08–0.16 mm，而当前预设的首层层高与层高均为 0.20 mm。预期在不兼容卡片中显示原因、该喷嘴的支持范围和当前预设的两个层高值。

## 原因与代码路径

`FilamentPanel::show_filament_grouping_dialog()` 通过 `make_filament_map_auto_input()` 获取 `nozzle_compatibility`，并据此设置卡片边框、标题颜色和悬浮提示。卡片正文原先只负责显示耗材块或“无耗材”，没有把导致不兼容的数值展示出来。

兼容性由 `PresetBundle::get_print_preset_nozzle_compatibility()` 判定。它读取工艺预设中的 `layer_height` 和 `initial_layer_print_height`，再调用 `is_nozzle_compatible_with_layer_heights()` 检查两个值是否都落在喷嘴范围内。喷嘴范围来自所选喷嘴规格的 `min_layer_height`、`max_layer_height`；配置值未指定或非正数时，分别按口径的 20% 和 75% 计算。

## 修改内容

- 在不兼容喷嘴卡片正文中显示“当前层高不在喷嘴 N 支持范围内”。
- 显示该喷嘴支持的层高上下限，以及当前工艺预设的首层层高、层高。显示值取自现有兼容性判断使用的喷嘴规格和工艺配置；小数最多保留四位，至少保留两位。
- 当不兼容卡片没有耗材时，以原因说明代替“无耗材”；已有耗材块仍保留。
- 为三条新增文案添加简体中文翻译。其他语言在翻译补齐前使用英文原文。

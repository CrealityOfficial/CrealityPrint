## 2. 问题描述

### 2.1 现象

模型执行自动朝向后，旋转结果可能扩大模型在 XY 平面的投影范围。现有流程保留实例原有的 XY 位置，仅将模型调整到打印板表面，因此原本位于打印板内的模型可能在旋转后部分越出可打印区域。

用户最终得到的是一个几何朝向已经计算完成、但空间位置不可打印的结果，需要自行发现越界并手动移动模型。

### 2.2 期望

- 自动朝向后的模型应尽量保持在所属打印板的可打印区域内。
- 当朝向后的模型可以通过平移放入打印板时，系统应自动完成位置修正。
- 当模型尺寸本身超过打印空间，或受排除区域等约束无法放入时，应继续保留越界状态，不能将其误判为可打印。

### 2.3 禅道处理建议

自动朝向完成后，如果模型超出打印板，则将模型在当前打印板内平移居中。

工程实现使用“实例原所属打印板”作为约束目标。相比直接使用界面当前打印板，这一处理能够保证多打印板场景中实例不会被错误移动到其他打印板。

## 3. 根因分析

### 3.1 朝向算法不包含打印空间参数

`orientation::OrientParams` 负责配置最小支撑面积、最小体积和最短打印时间等朝向评价参数，但不包含打印板轮廓、打印板原点或可打印区域约束。

因此，朝向计算只负责选择旋转矩阵，不负责决定旋转后的 XY 位置，也不能保证最终投影落在打印板内。

### 3.2 结果应用阶段只处理旋转和 Z 方向

原有 `OrientMesh::setter` 的处理顺序为：

1. 将朝向计算得到的旋转矩阵应用到 `ModelInstance`。
2. 使 `ModelObject` 的包围盒缓存失效。
3. 调用 `ModelObject::ensure_on_bed()` 将模型放到打印板表面。

`ensure_on_bed()` 仅修正 Z 方向，不处理 XY 位置。模型旋转后的 XY 包围盒发生变化时，实例仍保留原来的 XY 偏移，由此产生越界。

### 3.3 多入口存在重复实现

自动朝向结果原先由三条路径分别构造和应用：

- 标准异步 `OrientJob`。
- 简单模式工具栏的 GPU 朝向路径。
- AI Bridge 的 GPU 朝向路径。

三处均重复维护 `OrientMesh` 构造和结果回调。如果只修复其中一处，其他入口仍会产生不一致行为。

## 4. 设计方案

### 4.1 统一朝向输入构造

在 `OrientJob` 中提供统一的 `create_orientation_input()`：

- 接收 `ModelInstance`、模型索引和实例索引。
- 统一设置模型网格、模型名称和支撑阈值角度。
- 在回调中保留稳定的模型与实例定位信息。
- 标准任务、简单模式和 AI Bridge 共用同一实现。

该设计消除了三个入口之间的重复逻辑，后续朝向结果应用规则只需维护一处。

### 4.2 应用变换与打印板约束

`apply_orientation_transform()` 按以下顺序处理朝向结果：

1. 应用旋转矩阵。
2. 使模型包围盒缓存失效。
3. 调整 Z 方向，使模型落到打印板表面。
4. 根据模型索引和实例索引查询实例原所属打印板。
5. 使用打印板既有的 `check_outside()` 判断实例是否越界。
6. 若实例越界，计算实例凸包包围盒中心与打印板中心之间的 XY 平移量。
7. 通过 `ModelObject::translate_instance()` 平移当前实例，并同步更新包围盒状态。
8. 再次执行越界检查；如果仍然越界，保留现有越界状态并输出诊断日志。

平移向量定义为：

```text
translation.x = plate_center.x - instance_bounds_center.x
translation.y = plate_center.y - instance_bounds_center.y
translation.z = 0
```

该处理不会修改已经选定的朝向，也不会改变实例所属打印板。

### 4.3 无法满足约束时的处理

以下场景中，居中后模型仍可能越界：

- 模型旋转后的 XY 尺寸大于打印板可用尺寸。
- 模型与打印板排除区域相交。
- 异形或圆形打印板的实际轮廓无法容纳该投影。

此时不继续尝试缩放、重新朝向或自动排布，避免扩大本次修改的行为范围。系统继续通过原有刷新流程展示越界状态，并记录模型索引、实例索引和打印板索引，便于诊断。

## 6. 行为变化与兼容性

### 6.1 行为变化

- 朝向后仍位于所属打印板内的实例不发生 XY 位移。
- 朝向后越界的实例会移动到所属打印板中心。
- 模型无法放入时仍保持越界，不会自动缩放或切换到其他朝向。
- 模型不会因为界面当前选中打印板不同而跨板移动。

### 6.2 保持不变的行为

- 朝向候选生成和评分算法保持不变。
- 最小支撑面积、最小体积、最短耗时三种模式保持不变。
- GPU 计算及 CPU fallback 逻辑保持不变。
- 锁定打印板的过滤规则保持不变。
- Undo 快照、Plater 更新和切片状态刷新流程保持不变。

### 6.3 风险

- 多个越界实例分别居中时可能发生实例间重叠。本次修改解决打印空间边界，不承担完整自动排布职责。
- 当前处理依赖既有 `PartPlate::check_outside()` 语义，圆形、异形打印板和复杂排除区域需要重点回归。
- `ModelObject::ensure_on_bed()` 按对象处理 Z 方向；同一对象包含多个实例时，需要确认各实例原有 Z 状态没有非预期变化。
- 模型尺寸大于打印空间时，居中只能提供稳定位置，不能使模型变为可打印。

## 8. 回归建议

### 8.1 核心场景

1. 导入一个初始状态位于打印板内、朝向后 XY 投影会明显增大的模型。
2. 分别执行最小支撑面积、最小体积和最短耗时朝向。
3. 确认朝向后越界的模型自动移动到所属打印板中心。
4. 确认模型 Z 最小值位于打印板表面。
5. 确认模型不再显示越界警告，并可正常切片。

### 8.2 尺寸边界

- 模型朝向后尺寸略小于打印板：应居中并恢复为可打印状态。
- 模型尺寸等于打印板边界：确认浮点容差下状态稳定。
- 模型尺寸大于打印板：应居中但仍保持越界状态。
- 模型仅一个方向超限：确认只改变 XY 位置，不修改缩放和朝向。

### 8.3 多打印板与多实例

- 在非当前打印板上选择模型执行自动朝向，确认模型仍留在原打印板。
- 多个打印板同时存在模型时执行全局自动朝向，确认各实例按各自所属打印板约束。
- 同一 `ModelObject` 包含多个实例时，确认各实例的旋转、XY 位置和 Z 位置正确。
- 锁定打印板上的模型不应被朝向或移动。

### 8.4 入口一致性

- 标准模式工具栏自动朝向。
- 简单模式 GPU 自动朝向。
- GPU 不可用时的 CPU fallback。
- AI Bridge 自动朝向。
- 对每个入口分别执行撤销和重做，确认旋转与平移同时恢复。

### 8.5 打印板类型

- 矩形打印板。
- 圆形打印板。
- 自定义异形打印板。
- 包含排除区域的打印板。
- 重点确认居中后仍不满足约束的模型继续显示越界状态。

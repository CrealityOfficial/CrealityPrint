# Bug 17885 多喷嘴工艺百分比参数使用错误基准

## 1. 基本信息

- Bug ID：17885
- 标题：【F039】多喷嘴时加速度使用错误
- 禅道链接：未提供
- 反馈人：未提供
- 处理人：wangwenbin
- 分支：release-260930
- 影响模块：工艺百分比换算、G-code 导出、加速度超限提示、自定义 G-code 参数解析

## 2. 问题现象

- 用户反馈：导入 3MF 后，右侧使用 0.6 mm 喷嘴的模型在第三层显示加速度 5004，期望为 7003。
- 实际结果：内部实心填充加速度配置为 100%，却使用第一个物理喷嘴的普通打印加速度 5004 作为基准；导出的 G-code 已写入错误值。
- 期望结果：共用百分比按当前物理喷嘴的基准换算，右侧应为 `100% × 7003 = 7003 mm/s²`。

## 3. 复现步骤

- 前置条件：用户目录 `F:\result\2026bug修复\9月\17885 【F039】多喷嘴时加速度使用错误` 中的 `0.4-0.6立方体.3mf` 和 `立方体_PETG_2h54m.gcode`。
- 导入项目，使用项目保存的手动耗材映射和工艺配置，切片并查看第三层右侧模型的内部实心填充。
- 项目配置：喷嘴直径 `[0.4, 0.6, 0.4, 0.4]`，普通打印加速度 `[5004, 7003, 5004, 5004]`，内部实心填充加速度 `100%`。
- 右侧模型使用耗材 4，即 T3；`filament_map[3] = 2`，对应物理喷嘴索引 1。
- 原始 G-code：1969～1971 行为第三层 `Z:0.6`、`HEIGHT:0.2`；2614 行内墙加速度 4124、2625 行外墙加速度 7458 均正确；2644 行写入 `ACCEL=5004`，2645 行标记 `Internal solid infill`。
- 复现概率：未提供。已核对现有产物，未运行修复后版本重新切片。

## 4. 根因分析

- 触发条件：当前物理喷嘴并非数组第一项，各喷嘴的基准值不同，相关参数使用百分比。
- `GCode::_extrude()` 使用不带索引的 `get_abs_value()` 读取内部实心填充、桥接加速度和内部桥接速度；`Wipe::wipe()` 同样用于擦拭速度。
- `ConfigBase::get_abs_value()` 沿参数定义的 `ratio_over` 获取基准，但遇到数组固定使用 `get_at(0)`，丢失当前喷嘴信息。
- 原 `get_abs_value_at()` 仅支持浮点数组和浮点/百分比数组，未支持共用的浮点/百分比标量。
- `Print::validate()` 的全局和对象加速度检查同样使用首项读取，可能漏报其他喷嘴超限；全局入口还由第一个喷嘴的普通打印加速度决定是否检查。
- `PlaceholderParser` 的百分比依赖解析未处理 `coFloats` 数组基准：标量百分比可能解析失败，百分比数组的解析循环可能无法退出。

## 5. 修复方案

### 修改点

- `src/libslic3r/Config.cpp`：扩展 `get_abs_value_at()`，支持共用百分比标量，并沿 `ratio_over` 传递同一个索引；绝对值直接返回，保留单值数组回退和已有标量线宽零值继承规则。
- `src/libslic3r/GCode.cpp`：下表四项统一使用当前物理喷嘴索引换算，条件判断与实际取值使用相同接口。
- `src/libslic3r/Print.cpp`：全局和对象加速度检查按所用耗材映射到物理喷嘴，逐项换算后比较；对象检查纳入配置的支撑耗材，普通打印加速度为零的喷嘴沿用导出时不设置加速度的语义。
- `src/libslic3r/PlaceholderParser.cpp`：共用百分比和数组百分比占位符的基准为浮点数组时，按当前物理喷嘴取值。
- `tests/libslic3r/test_config.cpp`、`tests/libslic3r/test_placeholder_parser.cpp`：增加 Bug 17885 回归用例。

| 参数 | 保留的百分比基准 | 本次处理 |
|---|---|---|
| 内部实心填充加速度 | 当前喷嘴普通打印加速度 | 修复 |
| 桥接加速度 | 当前喷嘴外墙加速度 | 修复 |
| 内部桥接速度 | 当前喷嘴桥接速度 | 修复 |
| 擦拭速度 | 当前喷嘴空驶速度 | 修复；按路径角色决定擦拭速度的优先级和最低速度规则保留 |
| 稀疏填充加速度、悬垂速度 | 各自定义的当前喷嘴基准 | 导出原已按索引取值；检查共用接口兼容性，修复百分比占位符的数组基准解析 |
| 小周长速度、斜接缝速度、首层空驶速度 | 导出路径显式传入的当前喷嘴基准 | 静态核对，本次不修改 |
| 接缝间隙、填充重叠、填充锚定等几何百分比 | 当前流宽、间距、喷嘴直径等各自的几何基准 | 静态核对显式几何基准消费位置，保留原业务公式 |

共用百分比继续共用，不新增 UI 控件，不改变参数存储格式。机器加速度上限的选择和实际限幅规则保持原有实现，本次调整的是工艺取值及其百分比基准。

## 6. 验证清单

- 必测：原项目重新切片，第三层右侧内部实心填充输出 `ACCEL=7003`；左侧仍为 5004，右侧内墙 4124、外墙 7458。
- 必测：0.6 喷嘴桥接加速度 `50% × 7458 = 3729`；0.4 喷嘴按自身外墙加速度换算。
- 必测：两喷嘴桥接速度设为 30/60，内部桥接速度设为 150%，分别得到 45/90 mm/s；检查实际 G-code 时同时考虑流量和首层等限速规则。
- 必测：两喷嘴空驶速度设为 400/500，擦拭速度设为 80%，关闭按角色擦拭速度后，分别得到 320/400 mm/s。
- 必测：全局及对象工艺仅第二个使用中的喷嘴超限时能提示；第一个喷嘴普通打印加速度为零不应跳过其他使用中的喷嘴。
- 边界：耗材 4 映射到第二物理喷嘴；多个耗材共用喷嘴；支撑指定其他耗材或使用当前耗材；未使用喷嘴的配置不应触发本次校验。
- 反向：绝对值、零值、单值数组、百分比基准为零；单喷嘴配置；稀疏填充百分比和以层高为基准的标量百分比。
- 自定义 G-code：引用上述四个参数及稀疏填充加速度百分比，使用 T3 时按物理喷嘴索引 1 换算，避免数组基准解析失败或卡住。
- 已完成：原始 3MF/G-code 与源码交叉分析、改动差异及 UTF-8/BOM/换行格式检查、新增回归用例代码。
- 编译/测试结果：按用户规范未编译；新增 C++ 测试未执行，修复后未重新切片，GUI 和实机验证待完成。

## 7. 风险与回退

- 风险：原先错误使用首喷嘴基准的路径，其速度或加速度会恢复为当前喷嘴配置，打印时间和运动表现可能随之变化。
- 影响范围：百分比基准存在喷嘴独立值的消费路径，以及多喷嘴工艺加速度超限提示；共用接口的数组百分比调用也需回归。
- 回退方案：按本次补丁逐项回退对应源码和测试差异，无预设迁移或项目数据格式变更。

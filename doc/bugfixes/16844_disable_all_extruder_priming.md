# 16844 屏蔽所有挤出机画线参数

## 1. 基本信息
- Bug ID：16844
- 标题：【切片】“所有挤出机画线”参数不生效
- 反馈人：测试反馈
- 处理人：wangwenbin
- 影响模块/影响文件：`src/libslic3r/GCode.cpp`、`src/slic3r/GUI/Tab.cpp`、`src/slic3r/GUI/ConfigManipulation.cpp`、`src/slic3r/GUI/GLCanvas3D.cpp`

## 2. 现象与复现
- 复现场景：多耗材工程中开启擦拭塔，并使用“所有挤出机画线”参数。
- 实际结果：该参数在当前版本不再使用，继续暴露会引导用户开启未维护的首层多挤出机 priming 逻辑。
- 期望结果：当前版本屏蔽该参数入口，并确保旧项目中保存的开启状态不会影响 G-code 导出或预览。

## 4. 根因分析
- 触发条件：当前版本仍保留 `single_extruder_multi_material_priming` 参数入口和相关导出/预览分支。
- 代码链路：打印设置页展示参数 -> `ConfigManipulation` 控制参数显隐 -> G-code 导出判断参数并输出 priming -> 预览读取 wipe tower priming 数据。
- 为什么会出现该现象：参数功能在当前版本不使用，但历史逻辑仍可能被 UI 或旧 3MF 配置触发。

## 5. 修复方案
- 修复思路：保留配置 key 兼容旧项目，但在当前版本固定关闭该功能。
- 修改点：打印设置页不再追加 `single_extruder_multi_material_priming` 参数行。
- 修改点：动态显隐逻辑固定隐藏该参数。
- 修改点：G-code 导出固定按未启用所有挤出机画线处理，不输出对应 priming。
- 修改点：预览固定不加载该参数对应的 priming toolpath。

## 6. 影响范围与风险
- 正向影响：当前版本不会再显示或执行“所有挤出机画线”参数。
- 可能风险：旧项目中即使保存了该参数为开启，也会被当前版本忽略。
- 是否改变旧行为：仅屏蔽该参数自身功能，不改变擦拭塔、混色耗材统计、普通换料和普通 G-code 导出逻辑。

## 7. 回归建议
- 必测场景：打开打印设置，确认擦拭塔相关区域不显示“所有挤出机画线”参数。
- 必测场景：导入旧 3MF，旧配置中即使该参数为开启，也不输出 `CP PRIMING START` 对应首层所有挤出机画线。
- 边界场景：普通擦拭塔、普通换料和混色耗材切片结果不受影响。
- 反向场景：关闭擦拭塔或单耗材工程行为保持不变。

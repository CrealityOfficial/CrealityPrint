# Bug #18106 修复记录：独立浮雕缺少默认耗材

## 2. 问题现象

直接点击添加浮雕，浮雕文字已经生成，但准备页面出现“喷嘴耗材映射不完整”的错误提示，错误关联到浮雕文字对象。

## 3. 影响范围

- 模块：准备页面、独立浮雕对象创建。
- 修改文件：`src/slic3r/GUI/Jobs/EmbossJob.cpp`。
- 触发条件：独立浮雕没有对象级默认耗材，部件和工艺角色耗材均使用继承值 `0`。
- 已有对象上的浮雕部件仍继承所属对象的耗材；本次不修改该创建路径。

## 4. 修复前复现

禅道原始步骤仅描述“直接点击添加浮雕，会报错：喷嘴耗材映射不完整”。以下为根据代码补充的回归条件，尚未进行界面复现：

1. 使用墙、稀疏填充、实心填充耗材均设为跟随对象（`0`）的工艺。
2. 不选中已有对象，直接添加独立浮雕文字。
3. 等待后台参数校验，观察浮雕对象及错误通知。
4. 修复前对象未指定默认耗材，可能出现上述报错。

## 5. 原因分析

以下结论来自代码链路分析，并非禅道提供的运行时变量或调用栈：

1. `CreateObjectJob::finalize()` 创建独立浮雕时，只将部件的 `extruder` 设为 `0`（继承），没有为新对象设置默认耗材。普通网格对象的创建路径会设置对象 `extruder = 1`。
2. `PrintObject.cpp` 中 `apply_to_print_region_config()` 跳过值为 `0` 的 `extruder`。工艺角色耗材也为 `0` 时，缺少具体对象耗材可供继承，最终角色耗材仍为 `0`。
3. `Print::validate()` 通过 `resolve_model_flow_width()` 解析线宽对应的喷嘴。
4. `Flow.cpp` 中 `resolve_flow_nozzle_index()` 检测到 `filament_id == 0`，抛出“Filament nozzle mapping is incomplete.”，最终显示为浮雕对象的错误。

本次修复针对对象默认耗材缺失，不重建或重置项目喷嘴耗材映射。

## 6. 修复方案

创建独立浮雕对象后、加入对象列表并触发后台更新前，设置对象级 `extruder = 1`，与普通新建网格对象保持一致。部件仍保留 `extruder = 0`，通过对象获得有效的默认耗材。

该数值表示第一个耗材编号，不是强制使用物理喷嘴 1；实际喷嘴仍由既有耗材映射决定。

## 7. 代码变更摘要

- 函数：`CreateObjectJob::finalize()`。
- 新增：`new_object->config.set_key_value("extruder", new ConfigOptionInt(1));`。
- 新增注释说明对象默认耗材用于部件及工艺角色的继承。
- 未修改全局角色耗材设置、已有项目映射或已有对象上的浮雕部件创建逻辑。

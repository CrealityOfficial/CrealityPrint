# BUG 17500 100% 填充时自动顶面扩张过大导致轨迹变化和溢料

## 1. 基本信息

- Bug ID：`17500`
- 标题：`【引入】7.2.1版本切片路径有变化导致顶面出现溢料缺陷`
- 日期：`2026-07-31`
- 产品 / 模块：`Creality Print / 打印效果`
- 类型 / 严重程度 / 优先级：`代码错误 / 一般 / 中`
- 影响版本：禅道登记为`主干`，复现版本为 `7.2.1.5419`
- 对比正常版本：`7.1.1.4472`
- 报告人：`李昭勋`
- 指派给：`贺淼`
- 分支：`release-260731` 基线
- 关联回归 Bug：`#16660`

## 2. 问题现象

- 同一个 3MF 使用 `7.1.1.4472` 和 `7.2.1.5419` 切片后，顶面走线轨迹不一致。
- `7.2.1.5419` 打印件顶面出现一道明显突起和溢料痕迹，`7.1.1.4472` 无此现象。
- 问题模型为 100% 填充的复杂 HueForge 薄片，包含大量细碎闭合轮廓，顶面区域扩张变化会明显放大轨迹合并和角色重分类的影响。

## 3. 影响范围

- 模块：外表面识别及顶面 / 内部实心填充区域划分。
- 关键文件：`src/libslic3r/LayerRegion.cpp`
- 关键函数：`LayerRegion::process_external_surfaces(...)`
- 触发条件：
  - `sparse_infill_density = 100%`；
  - `external_infill_margin` 使用自动值（配置值为 `0`）；
  - 模型存在大量细小或相邻的顶面轮廓时更明显。
- 不受本次修改影响：
  - 用户显式配置的非零顶 / 底面扩张距离；
  - 非 100% 填充时现有的自动扩张策略；
  - 无墙模型原有的最小 epsilon 回退。

## 4. 修复前复现步骤

1. 使用 `7.2.1.5419` 打开问题文件 `顶面.3mf`。
2. 保持项目中的 100% 填充、自动顶 / 底面扩张等参数并切片。
3. 与 `7.1.1.4472` 的切片结果对比顶面路径。
4. 可见新版本的 Top surface 范围增大、Internal solid 范围缩小，局部走线发生合并和角色变化。
5. 打印后顶面形成明显突起痕迹。

## 5. 根因分析

直接引入变更为提交 `daace149a93b8a25043d27afd52a0c4143cfdeac`。该提交为修复 `#16660`，放大了自动顶面扩张距离：

- 旧默认值约为：

  `（外墙线宽 + 内墙间距）/ 2 + 内墙间距 ×（墙圈数 - 1）`

- 新默认值约为：

  `（0.5 × 外墙线宽 + 外墙间距 + 内墙间距 ×（墙圈数 - 1））× sqrt(2)`

在问题配置下，自动扩张距离从约 `0.821 mm` 增加到约 `1.406 mm`，增幅约 `71.3%`。

100% 填充会在后续流程中把内部填充整体转换为 Internal solid。此时不存在稀疏填充区域供外表面向内锚定，较大的自动扩张距离会把大量 Internal solid 重新划入 Top surface。对问题模型的 G-code 统计显示：

- Top surface 路径长度增加约 `1316.026 mm`；
- Internal solid 路径长度减少约 `1286.842 mm`；
- 两者总长度仅增加约 `29.184 mm`。

因此问题主要不是总挤出量整体增加，而是约 `1.3 m` 路径在 Top surface 与 Internal solid 之间被重新分类，导致复杂细碎区域的路径连接方式和局部堆料发生变化，最终形成顶面突起。

## 6. 修复策略

- 将“最大扩张参考值”与“自动默认扩张值”拆分为 `max_margin` 和 `default_margin`。
- `max_margin` 继续作为显式百分比配置的计算基准，保证用户配置语义不变。
- 仅当填充密度为 `100%` 且扩张配置为自动值时，`default_margin` 使用较小的旧默认公式，避免大面积重分类 Internal solid。
- 非 100% 填充继续使用 `#16660` 引入的 `sqrt(2)` 扩张策略，防止薄片模型第二层重新出现零碎 Internal solid 条带。
- 显式非零扩张值保持原有逻辑，不被自动回退覆盖。

## 7. 代码修改摘要

- 文件：`src/libslic3r/LayerRegion.cpp`
  - 缓存 `sparse_infill_density`，统一用于条件判断。
  - 新增 `default_margin`，与 `max_margin` 分别承载自动回退值和配置计算基准。
  - 100% 填充时为自动扩张恢复较小的旧默认值。
  - `external_infill_margin` 小于 epsilon 时改为回退到 `default_margin`。

## 9. 相关提交与排查记录

- `daace149a93b8a25043d27afd52a0c4143cfdeac`
  - 为 `#16660` 增大自动顶面扩张距离，是 `#17500` 的直接引入点。
- `#16660` 的原问题边界：
  - 15% 填充的薄片模型第二层残留大量细碎 Internal solid 条带；
  - 增强后的扩张距离能够覆盖这些条带并形成连续 Top surface；
  - 因此不能全局回退 `daace149`，必须按 100% 填充场景限定修复。

## 10. 回滚与风险

- 风险等级：中低。修改仅影响 100% 填充且使用自动扩张值的场景。
- 需要关注：
  - 100% 填充模型的斜面、窄顶面和复杂细节区域；
  - Top surface 与 Internal solid 的比例及连接方式；
  - 显式百分比或绝对扩张距离是否保持原有结果；
  - `#16660` 薄片模型第二层是否仍为连续顶面。
- 回滚方式：撤销 `LayerRegion.cpp` 中 `default_margin` 与 100% 填充分支，恢复统一使用 `max_margin` 的逻辑。

## 11. 后续建议

- 将 `#17500` 与 `#16660` 的 3MF 同时加入切片回归集，分别覆盖 100% 和普通填充密度。
- 增加 Top surface / Internal solid 角色面积或路径长度的基准检查，避免自动扩张策略再次造成大规模角色重分类。

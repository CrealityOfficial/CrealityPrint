## 2. 问题现象

### 用户反馈现象

添加 F039 机型并切换不同喷嘴后，分别查看耗材参数和速度/工艺参数：

- 速度/工艺参数页使用文字加绿色下划线表示当前喷嘴。
- 耗材参数页使用深色圆角分段按钮，选中项为绿色填充。
- 两个入口承担相同的喷嘴参数切换职责，但控件外观、选中反馈和上下留白不一致。

### 实际结果

同一个 `MultiSwitchBoard` 控件支持两种样式：

- `Style::Segmented`：深色圆角底板加绿色选中块。
- `Style::Underline`：普通文字加绿色文字和下划线选中态。

速度/工艺参数页显式使用 `Style::Underline`，耗材参数页未传入样式参数，因此使用默认的 `Style::Segmented`，最终产生禅道截图中的 UI 差异。

此外，两处选择器的垂直边距分别为 `4 DIP` 和 `8 DIP`。耗材选择器也没有独立接入主题切换刷新链路，切换深浅色主题后存在背景色不能立即与父容器同步的风险。

### 期望结果

- 速度/工艺参数页和耗材参数页使用一致的喷嘴选择样式。
- 当前喷嘴统一通过绿色文字和绿色下划线标识。
- 两处选择器的尺寸、上下留白和深浅色主题表现保持一致。
- UI 调整不改变喷嘴选项、当前选择、参数索引映射和切换后的参数刷新逻辑。

## 3. 复现步骤

### 前置条件

- 使用支持多物理喷嘴和多喷嘴变体的 F039/K3 机型。
- 当前页面存在按喷嘴区分的耗材参数和工艺参数。

### 操作步骤

1. 启动 Creality Print，并添加或选择 F039/K3 机型。
2. 在准备页面打开耗材参数。
3. 进入包含喷嘴差异参数的页面，观察顶部喷嘴选择器。
4. 返回准备页面，打开速度/工艺参数。
5. 进入包含喷嘴差异参数的页面，观察顶部喷嘴选择器。
6. 对比两处选择器的背景、选中态、文字颜色和上下间距。

### 复现结果

- 耗材参数页显示圆角分段按钮样式。
- 速度/工艺参数页显示下划线标签样式。
- 两处 UI 不一致，但点击选项后均能切换对应喷嘴参数。

### 复现概率

在 F039/K3 多喷嘴机型下稳定复现；单喷嘴机型或当前页面没有喷嘴差异参数时，选择器不会显示。

## 4. 根因分析

### 代码链路

1. `MultiSwitchBoard` 在 `SwitchButton.hpp/.cpp` 中提供 `Segmented` 和 `Underline` 两种绘制模式。
2. 速度/工艺参数页在 `Tab::create_preset_tab()` 中创建 `m_process_variant_switch`，显式传入 `MultiSwitchBoard::Style::Underline`。
3. 耗材参数页在 `TabFilament::create_preset_tab()` 中创建 `FilamentVariantTabState::switch_board`，旧代码只传入父窗口。
4. `MultiSwitchBoard` 的默认样式是 `Style::Segmented`，因此耗材参数页继续显示分段按钮。
5. 两个选择器位于不同的成员/状态管理路径中，通用 `Tab::sys_color_changed()` 只刷新 `m_process_variant_switch`，不会自动刷新保存在 `FilamentVariantTabState` 中的耗材选择器。

### 直接原因

Git 历史显示，提交 `ae6c587d3ab8e3d569fe2da53def5aafdae04580`（`feat:F039多口径UI`）将速度/工艺选择器改为下划线样式，并将其垂直边距从 `8 DIP` 调整为 `4 DIP`；耗材选择器仍保留后续默认的分段样式和 `8 DIP` 边距，导致两处 UI 分化。

该问题只影响显示和主题刷新，不是喷嘴参数数据不一致：耗材选择器原有的选项生成、配置行索引、选择事件和参数重载链路仍然正常。

## 5. 修复方案

### 修复思路

复用现有 `MultiSwitchBoard::Style::Underline`，让耗材参数页遵循速度/工艺参数页已经采用的样式规范，不新增控件、不复制绘制逻辑，也不修改参数切换业务。

### 代码变更摘要

- `src/slic3r/GUI/Tab.cpp`
  - `TabFilament::create_preset_tab()` 创建耗材喷嘴选择器时显式传入 `MultiSwitchBoard::Style::Underline`。
  - 将耗材选择器的上下边距从 `8 DIP` 调整为 `4 DIP`，与速度/工艺选择器保持一致。
  - 新增 `TabFilament::sys_color_changed()`：先执行 `Tab::sys_color_changed()`，再调用耗材 `MultiSwitchBoard::sys_color_changed()`，使选择器在深浅色主题切换时重新读取父容器背景并刷新。
- `src/slic3r/GUI/Tab.hpp`
  - 为 `TabFilament` 声明 `sys_color_changed() override`。

### 保持不变的逻辑

- 喷嘴标签仍由 `filament_nozzle_variant_label()` 生成。
- 可选喷嘴仍来自 `filament_nozzle_variants()`。
- 选择事件仍调用 `select_filament_nozzle_variant(event.GetInt(), true)`。
- 选中项仍映射到 `FilamentVariantTabState::nozzle_config_indices` 对应的配置行。
- 页面显隐条件、参数重载、脏状态和预设数据均未改变。
- `MultiSwitchBoard` 的通用绘制实现未修改，速度/工艺页及其他调用方行为不受影响。

## 7. 风险与回退

### 可能风险

- 耗材选择器由带底色的分段按钮改为无底板的下划线样式后，实际背景完全依赖父容器颜色；如果后续更换父窗口层级，需要继续保证 `sys_color_changed()` 可以取得正确背景。
- 长文本在下划线样式中按分段可用宽度截断，需关注本地化文案和多选项场景下的可读性。
- `TabFilament::sys_color_changed()` 先调用基类再刷新耗材选择器，后续如果基类主题刷新流程改变，需要同步检查调用顺序。

### 风险等级

低。修改集中在已有控件的样式参数、布局边距和主题刷新，不涉及喷嘴配置读写、预设迁移、切片或 G-code 生成。

### 回退方案

- 将耗材选择器构造恢复为默认 `MultiSwitchBoard(panel)`。
- 将耗材选择器上下边距恢复为 `8 DIP`。
- 移除 `TabFilament::sys_color_changed()` 的声明和实现。

回退后参数切换功能仍可工作，但耗材与速度/工艺选择器的 UI 不一致问题会重新出现。

# Bug 17301：F039 支撑缺省耗材被静默指定

## 1. 基本信息

- Bug ID：17301
- 标题：【F039】支撑默认值错误
- 禅道链接：未提供
- 创建人：未提供
- 处理人：wangwenbin
- 分支：release-260930
- 影响模块：工艺参数联动、切片配置应用、支撑耗材选择

## 2. 问题现象

- 用户导入 `Overhang.3mf` 后切片，支撑集中使用同一个耗材；将喷嘴2从 0.6 改为 0.4 后重新切片，支撑恢复使用缺省规则。
- 工程保存的 `support_filament`、`support_interface_filament` 均为 0。异常 G-code 两项却为 1，正常 G-code 两项为 0。
- 期望：保持用户选择；闲置异径喷嘴不应影响支撑缺省值。真正参与打印的喷嘴存在不同直径时，支撑仍为缺省应提示用户明确指定，而非自动写成耗材1。
- “缺省”表示不指定专用支撑耗材，按当前耗材等既有规则选择，不承诺每个模型的支撑必然使用该模型耗材。

## 3. 复现步骤

- 前置条件：F039 / Creality K3，四喷嘴直径为 `0.4,0.6,0.4,0.4`，启用支撑，支撑及接触面耗材为缺省，墙耗材为 0。
- 资料目录：`F:\result\2026bug修复\9月\17301 【F039】支撑默认值错误`。
1. 导入原始 `Overhang.3mf`。
2. 切片并导出 `111-Overhang_PLA_1h56m.gcode`。
3. 将喷嘴2从 0.6 改为 0.4，不手动修改支撑耗材。
4. 切片并导出 `222-Overhang_PLA_2h0m.gcode`。
- 复现结果：111 中支撑两项为 `1/1`；222 中为 `0/0`。
- 复现概率：本次日志复现成功，未统计概率。

## 4. 根因分析

### 触发条件与代码链路

- `Print::apply()` 接收配置副本 `new_full_config`，旧逻辑检查全部物理喷嘴直径；只要存在异径，就将缺省支撑改为墙耗材，墙耗材为 0 时回退到耗材1。
- `Tab::on_value_change("wall_filament")` 另有同类联动，也会修改工艺中的缺省支撑。两处都未按实际使用耗材映射筛选喷嘴。
- 切片校验 `Print::validate()` 已使用 `extruders()` 收集使用的耗材，通过 `get_physical_nozzle_diameter()` / `get_physical_nozzle_index()` 按 `filament_map` 读取物理直径，并对异径且仍使用缺省支撑的对象返回错误。
- 旧配置改写提前把 0 改成 1，导致该缺省支撑校验无法发现问题。

### 两组文件的差别

- 原始 `04-04-Overhang_PLA_2h0m.gcode` 与 `ok-04-04-Overhang_PLA_2h0m.gcode` 的映射均为 `1,3,1,1`，使用喷嘴1和3，0.6 喷嘴2闲置。
- 本次 111 与 222 的映射均为 `1,2,1,1`；111 真正使用 0.4 和 0.6，222 全部为 0.4。
- 修复后两种情况预期不同：前者允许缺省支撑；后者的 111 场景应提示明确指定支撑耗材。

## 5. 修复方案

- `src/slic3r/GUI/Tab.cpp`：删除墙耗材回调中的支撑缺省值强制联动。
- `src/libslic3r/PrintApply.cpp`：删除异径时改写 `new_full_config` 支撑两项的逻辑。
- 复用现有 `Print::validate()` 实际映射校验，不新增另一套异径判断；保留现有“混合喷嘴直径时必须明确指定支撑耗材”错误提示。
- 不添加“固定耗材→缺省”自动恢复，避免覆盖用户明确指定的耗材。
- 清理此次 `SupportDefaultDiag:17301` 临时日志及专用头文件。
- 后台编辑预校验与正式切片校验区分阶段，分组前不使用旧映射报支撑缺省错误。
  - `Print.cpp / Print.hpp`：增加显式的分组前预校验入口参数，统一暂缓依赖最终喷嘴映射的几何检查：异径支撑/擦料塔限制、层高与喷嘴直径及推荐范围、模型与支撑线宽（含首层/筏层）、裙边/底边线宽、有机支撑尖端和分支尺寸与 Flow 线宽的比较。原三参数虚函数入口保持完整校验，其他调用者默认严格。
  - `BackgroundSlicingProcess.cpp / .hpp`：传递预校验阶段，默认仍为完整校验。
  - `Plater.cpp`：按现有分组入口条件（待处理工程映射，或支持映射且选中不同喷嘴规格）判断是否等待分组，不用 `Manual` 模式代替确认状态。后台更新和盘选择预校验暂缓上述依赖映射的检查；材料有效性、参数互斥、支撑涂绘提示，以及树支撑分支直径不得小于尖端直径等独立检查继续执行。
  - 分组前预校验返回单独的待分组状态；后台启动入口同时检查阶段状态，禁止把预校验成功当成可启动切片。校验阶段变化时即使配置未变也重新校验，清理旧错误。
  - 单盘和全部切片保留原来的“分组确认并同步映射 → reslice → 强制完整校验 → 启动切片”顺序。导出、其他强制校验和直接引擎校验仍严格执行。
  - 不新增持久化“已确认分组”标志：普通后台检查始终按预校验处理，需要实际启动任务的入口执行完整校验，避免确认标志在参数变化或切盘后失效。
- 简体和繁体提示统一为明确指定支撑耗材，不再要求用户“指定喷嘴”。

### 线宽工程补充

`线宽太小-Overhang.3mf` 保存喷嘴直径 `0.2,0.6,0.4,0.6`、映射 `1,2,1,1`、支撑两项为 0、层高为 0.2，喷嘴1的支撑线宽为 0.2。旧预校验按临时映射取到该支撑 Flow，因 `线宽 <= 层高` 提前报错。仅暂缓“异径必须指定耗材”不足以解决问题：分组还会改变模型和支撑 Flow、层高推荐范围、裙边等参数来源。因此上述几何检查统一推迟到最终映射确认后，既不修改用户参数，也不取消正式校验。

在该工程中，分组到 0.4 喷嘴后应按 0.4 的支撑线宽检查；若最终使用 0.2 且支撑线宽仍为 0.2、层高仍为 0.2，正式校验仍应报线宽太小。实际异径且保留缺省时，先报告明确指定支撑耗材。

## 7. 风险与回退

- 真正异径且仍选缺省支撑的工程将出现已有校验提示，用户需要明确指定支撑及接触面耗材，这是本次预期行为。
- 已经被旧版本保存为固定耗材的工程不自动迁移；无法区分自动改值与用户主动指定，需由用户选择缺省。
- 两处旧逻辑是共享路径，需覆盖普通多喷嘴机型的回归；现有其他支撑参数联动和校验保持不变。
- 需要分组的 GUI 预校验阶段不再自动启动后台切片，用户点击切片完成分组后启动；需验证取消、重分组、全部切片以及导出入口。
- 回退：撤回本次校验阶段传递及后台启动保护，并恢复两处被删除的自动改值逻辑；这也会恢复原静默改值和提前提示问题。诊断日志无需恢复。

# Bug 18038：层高推荐范围与切片硬性校验分离

## 1. 基本信息
- Bug ID：18038
- 标题：附件 3MF 选中盘 3 切片失败，提示当前工艺层高与所有已配置喷嘴均不兼容
- 禅道链接：未提供
- 创建人：杨艳虹
- 处理人：wangwenbin
- 分支：release-260930
- 影响模块：耗材喷嘴映射、分组界面、层高校验、切片及 G-code 导出

## 2. 问题现象
- 用户反馈：导入附件后选择盘 3，切片报错；7.2.1 可以正常切片。
- 实际结果：首层超过打印机的最大推荐层高，唯一喷嘴被判定不兼容。
- 期望结果：超出推荐范围只警告；超过实际使用喷嘴直径等硬性条件时才阻止切片。单喷嘴和多喷嘴执行同一规则。

## 3. 复现步骤
- 前置条件：附件 `E8B4A7E69EB6E694B6E7BAB3E68993E58DB0.3mf`，Ender-3 V3 KE，喷嘴 0.4 mm，普通层高 0.2 mm，首层 0.4 mm，推荐范围 0.08～0.36 mm。

1. 导入附件。
2. 选择盘 3。
3. 点击切片单盘。

- 复现结果：提示“当前工艺层高与所有已配置喷嘴均不兼容”。
- 复现概率：未提供；本次未运行 GUI 复现。

## 4. 根因分析
- `Print::resolve_filament_mapping()` 将普通层高、首层层高与喷嘴最小/最大推荐层高进行硬性比较。
- `resolve_effective_filament_map()` 在兼容喷嘴为空时直接报错，且手动映射同样受此限制。
- 首层 0.4 > 推荐最大值 0.36，因此唯一喷嘴被排除；原有“层高不得超过喷嘴直径”检查允许 0.4 == 0.4。
- 工艺列表的推荐筛选、自动映射偏好、手动映射可用性和切片合法性共用了同一种兼容结果。
- 附件保存的盘 3 G-code 来自 5.1.4，包含首层 `Z:0.4 / HEIGHT:0.4`；7.2.1 可切片为用户反馈，未独立复验。

## 5. 修复方案
- `PrintConfig.hpp/.cpp`：增加共享硬性判断（有效正值且不超过喷嘴直径）；映射输入拆分为硬性可用集合和推荐集合。自动分配优先使用推荐且可用的喷嘴，无推荐候选时回退到硬性可用集合；手动分配不因超推荐范围而失败。
- `PresetBundle.hpp/.cpp`：保留工艺列表默认的推荐范围筛选；映射初始化单独取得硬性可用结果和推荐结果。
- `FilamentPanel.cpp`：分组界面超推荐范围显示警告但允许拖放；违反硬性条件仍不可分配。
- `localization/i18n/zh_CN/CrealityPrint_zh_CN.po`：补充分组卡片和后端提示的中文翻译；卡片正文省略重复喷嘴编号，独立切片提示保留定位信息。
- 卡片展示收敛为三态：推荐范围内正常显示；超推荐范围使用黄色“超推荐范围”及“可使用，可能影响打印质量”；违反硬条件使用红色“不可用”，保留原有“当前层高不在喷嘴支持范围内”的提示，并动态显示“层高和首层层高须大于 0，且不超过喷嘴直径”。直径来自当前卡片选中规格，不写死为 0.20 mm；保留当前首层/普通层高数值，不增加确认弹窗。
- `Print.cpp`：切片、导出的映射及对象/首层/变层高复检使用硬上限；切片验证根据对象使用的喷嘴提供非阻断推荐范围警告，并将原整盘最小直径检查收窄到对象使用的喷嘴。耗材收集覆盖区域、模型体、高度范围、显式支撑及混色成员。
- 保留多喷嘴工艺列表的并集规则：至少一个当前喷嘴同时推荐普通层高和首层层高。保留当前选中项例外。
- 不修改自适应/可变层高的生成、平滑和限幅算法，不修改原附件和打印机推荐范围。
- 参考本地 BambuStudio 02.08.02.61 的推荐范围与喷嘴直径校验区分；首层推荐范围警告为本次统一规则的补充。

- 自动模式在无推荐喷嘴时允许回退，须验证映射结果与设备实际配置一致；手动模式保留用户选择。

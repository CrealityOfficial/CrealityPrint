# Bug 18065：【急】挤出机参数置灰了

## 1. 基本信息

- Bug ID：18065
- 标题：【急】挤出机参数置灰了
- 禅道链接：未提供，未访问禅道页面。
- 创建人：康美樱
- 处理人：wangwenbin

- 影响模块：打印机设置 / 挤出机参数 / 回抽参数联动。

## 2. 问题现象

- 用户反馈：K3 机型的挤出机 1 页面，多项回抽参数置灰。
- 实际结果：截图中回抽长度为 `0 mm`，长度输入框、额外回填长度、回抽时抬升 Z、回抽速度、装填速度、空驶距离阈值、换层时回抽及擦拭相关控件不可编辑；抬 Z 类型和空驶抬高角度仍可编辑。
- 期望结果：未启用固件回抽时，回抽长度应始终可编辑；长度为 0 时允许关闭相关从属参数，用户将长度改为正值后应恢复相应参数的编辑能力。

## 3. 复现步骤

- 前置条件：选择 Creality K3；关闭固件回抽；目标喷嘴当前变体的 `retraction_length` 为 0。该界面问题不依赖特定材料或模型。
- 操作步骤：
  1. 打开打印机设置，进入“挤出机 1”。
  2. 选择回抽长度为 0 的喷嘴变体，或在允许编辑时将回抽长度设为 0。
  3. 查看回抽区域，尝试将长度改回正值。
- 复现结果：相关控件置灰，回抽长度自身也被禁用，无法通过长度输入框重新开启回抽。
- 当前仓库 K3 预设中，每个物理喷嘴的 0.4 mm 变体回抽长度为 2 mm，0.2 / 0.6 / 0.8 mm 变体为 0 mm，可用于构造验证场景。
- 用户截图未显示当前口径，实际选择的喷嘴变体待补充；上述步骤根据代码和预设推导，尚未进行 GUI 实测。
- 复现概率：未提供。

## 4. 根因分析

- 触发条件：当前参数行回抽长度为 0，且 `use_firmware_retraction` 为 false。
- 代码链路：`TabPrinter::toggle_options()` → `printer_nozzle_variant_config_index()` 定位当前物理喷嘴及变体参数行 → `Tab::toggle_option()` → 控件启用状态更新。
- `TabPrinter::toggle_options()` 先通过 `!use_firmware_retraction` 允许编辑 `retraction_length`，随后计算：

  ```cpp
  bool have_retract_length = m_config->opt_float("retraction_length", variant_i) > 0;
  bool retraction = have_retract_length || use_firmware_retraction;
  ```

- 后续批量联动列表错误地包含 `retraction_length`，以 `retraction && !use_firmware_retraction` 再次设置其启用状态。长度为 0 时，该判断覆盖前面的允许编辑状态，形成“长度为 0 → 长度控件禁用 → 无法改回正值”的自锁。
- 其他回抽从属参数置灰符合现有联动规则；缺陷在于把开启回抽所需的长度输入框也禁用了。抬 Z 类型及空驶抬高角度未使用同一回抽开关条件，因此截图中仍可编辑。
- 该逻辑位于公共打印机设置页面，不限于 K3 或喷嘴 1。

## 5. 修复方案

- 修复思路：回抽长度作为控制回抽开关的基础参数，只由固件回抽模式决定是否可编辑，不依赖其自身是否大于 0。
- 修改文件：`src/slic3r/GUI/Tab.cpp`。
- 修改点：从 `TabPrinter::toggle_options()` 的批量回抽联动列表中移除 `retraction_length`，保留前面的独立判断：

  ```cpp
  toggle_option("retraction_length", !use_firmware_retraction, variant_i);
  ```

- 实际代码差异仅一行；保留喷嘴变体参数行映射、固件回抽限制和其他参数的依赖关系，不修改 K3 预设值及切片计算逻辑。

## 7. 风险与回退

- 可能风险：公共界面联动调整，需要回归普通单喷嘴和固件回抽模式。
- 风险影响范围：打印机设置页回抽长度输入框的可编辑性；没有直接修改 G-code 生成或参数默认值。用户修改回抽长度后，切片仍按既有参数消费逻辑生效。
- 回退方案：反向应用本次单行变更，将 `retraction_length` 加回批量联动列表；回退后会恢复零值自锁问题。避免整文件回退覆盖其他改动。

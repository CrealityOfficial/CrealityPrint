# Bug 17883：悬垂速度多喷嘴参数 UI 显示问题

## 1. 基本信息

- Bug ID：`17883`
- 标题：UI显示问题——悬垂速度多喷嘴参数分组与显隐不合理
- 禅道链接：未提供
- 反馈人：康美樱
- 处理人：wangwenbin
- 分支：`release-260930`
- 影响模块：工艺参数页 → 速度 → 悬垂速度，多喷嘴控件及显隐联动

## 2. 问题现象

- 用户反馈现象：仅勾选 0.2-标准、0.4-标准的“悬垂降速”，下方仍显示全部喷嘴的速度设置。
- 实际结果：原界面按百分比分组，每个百分比下展开所有喷嘴。同一喷嘴的四档速度分散，未启用喷嘴占据界面空间。
- 期望结果：只显示已启用的喷嘴，按喷嘴连续排列 10% / 25% / 50% / 75%。左侧保留百分比，右侧输入框前仅在 10% 行显示一次喷嘴名称和冒号，后续行不显示名称或冒号，输入框对齐。
- 取消勾选只隐藏设置，保留原数值，重新勾选后恢复显示。

期望布局示意（数值仅作示例）：

```text
10%    0.2-标准: [ 0 ]
25%             [50 ]
50%             [30 ]
75%             [10 ]

10%    0.4-标准: [ 0 ]
25%             [50 ]
50%             [30 ]
75%             [10 ]
```

## 3. 复现步骤

前置条件：使用可显示 0.2-标准、0.4-标准、0.6-标准、0.8-标准参数的多喷嘴工艺配置。具体机型、材料、模型及完整项目未提供。

1. 打开工艺参数页“速度 → 悬垂速度”。
2. 仅勾选 0.2-标准、0.4-标准的“悬垂降速”，取消其余喷嘴。
3. 查看下方速度参数的分组、标签与显示范围。

复现结果：原界面仍按百分比展开全部喷嘴，未按对应开关分别隐藏。复现概率未提供。

## 4. 根因分析

- 触发条件：工艺参数具有多个喷嘴变体，悬垂速度使用通用多变体控件。
- 代码链路：TabPrint 构建参数组 → ConfigOptionsGroup::get_option() 使用 MultiVariantField → 每个速度参数分别展开全部喷嘴；TabPrint::toggle_options() 调用 ConfigManipulation::toggle_print_fff_options() 控制显隐。
- 问题原因：原界面按速度参数逐行构建，形成“百分比 → 喷嘴”的顺序；原显隐逻辑只读取 enable_overhang_speed 的索引 0，控制整条参数行，没有逐喷嘴判断。
- 标签布局要求：百分比与喷嘴名称需要分开，喷嘴名称每组只出现一次，不能拼接在左侧或在每行重复显示。

## 5. 修复方案

根据当前喷嘴布局重建完整悬垂参数组，按实际配置索引绑定原生输入框；按对应喷嘴开关显隐，隐藏时不清空参数。

| 文件 | 修改点 |
| --- | --- |
| src/slic3r/GUI/OptionsGroup.cpp | refresh_overhang_layout() 根据 get_multi_variant_input_layout() 获取喷嘴及源索引，按喷嘴连续生成速度行，布局变化时重建控件；经典模式的完全悬垂速度归入对应喷嘴。 |
| src/slic3r/GUI/OptionsGroup.cpp | update_overhang_visibility() 逐喷嘴控制显隐，共享选项按至少一个喷嘴启用及经典模式规则显示；恢复参数时匹配喷嘴身份。 |
| src/slic3r/GUI/OptionsGroup.hpp | 增加布局缓存、刷新入口、field_prefix 和 show_field_prefix_name，将喷嘴名称与百分比标签分开。 |
| src/slic3r/GUI/OG_CustomCtrl.cpp | 预留统一的喷嘴名称宽度，仅第一档绘制名称与冒号；后续档位保留空白占位，输入框对齐，复用既有主题颜色。 |
| src/slic3r/GUI/Tab.cpp | 通用显隐更新后补充逐喷嘴显隐；按源索引查找字段，支持值回填、修改状态与恢复按钮。 |

本次不修改切片速度计算公式。布局转换针对包含完整悬垂开关和速度行的参数组，局部覆盖参数页需单独回归。

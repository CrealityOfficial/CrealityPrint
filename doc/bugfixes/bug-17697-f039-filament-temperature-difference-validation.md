# Bug 17697 修复说明：F039 高低温耗材混合打印未提示

## 1. 基本信息

- Bug ID：`17697`
- 标题：`【F039】耗材温差较大的两个耗材分在一个组里面打印，没有报错提示`
- 禅道链接：https://zentao.creality.com/zentao/bug-view-17697.html
- 反馈人：康美樱
- 处理人：wangwenbin
- 分支：`feature/f039_group`
- 影响模块：F039/K3 多喷嘴切片前校验、耗材温度兼容性校验

## 2. 问题现象

- 用户反馈现象：在 F039/K3 上使用温差较大的两种耗材，例如低温组的 PLA 与高温组的 ABS，分组后执行切片，没有出现材料温度不兼容的报错提示。
- 实际结果：普通单喷嘴机型会提示“不能将温度差异过大的材料一起打印”，K3 配置相同材料组合时校验被跳过，只显示其他无关警告，仍可继续切片。
- 期望结果：只要当前打印范围内实际使用的材料同时包含高温组和低温组，就执行统一的安全校验；逐层打印按整板检查，逐对象打印按每个对象分别检查。

## 3. 复现步骤

### 前置条件

- 机型：Creality K3（F039 多喷嘴机型）。
- 材料：至少选择一种低温组耗材和一种高温组耗材，例如 Hyper PLA 与 CR-ABS。
- 模型：同一打印板上实际使用上述两种耗材；可将两种耗材分入同一组。
- 入口：准备页切片入口。

### 操作步骤

1. 选择 Creality K3 机型。
2. 添加 Hyper PLA 和 CR-ABS，并让当前打印板上的模型实际使用这两种耗材。
3. 完成耗材与喷嘴分组。
4. 点击切片。
5. 观察准备页左下角的切片校验提示。

### 复现结果

- 修复前：K3 没有显示高低温耗材混合打印错误。
- 对照单喷嘴机型：相同材料组合能够显示高低温耗材不兼容错误。

### 复现概率

- 满足 K3 多喷嘴配置、使用材料数大于 1 且同时包含高温组与低温组时稳定复现。

## 4. 根因分析

### 触发条件

- `Print::validate()` 获取到多个实际使用的逻辑耗材。
- `filament_type` 同时包含高温组与低温组材料。
- K3 的 `nozzle_diameter` 配置包含 4 个物理喷嘴。

### 代码链路

1. 切片前由 `Print::validate()` 执行打印配置校验。
2. 原逻辑只有在 `nozzle_diameter.size() < 2`、使用材料数大于 1、并且不是逐对象打印时，才调用 `Print::check_multi_filament_valid()`。
3. K3 的物理喷嘴数量为 4，`nozzle_diameter.size() < 2` 为假，因此材料温度兼容性检查没有执行。
4. `check_multi_filament_valid()` 原有能力可以根据实际使用耗材的 `filament_type` 调用 `creality::Filament::check_multi_filaments_compatibility()`，识别高温组与低温组同时出现的情况，但入口条件阻断了 K3。

### 问题原因

- 历史条件把“物理喷嘴数量”误当成了“是否需要检查材料温度兼容性”的依据。
- 多喷嘴并不能消除整板打印时的材料环境风险，例如热床/腔体条件、停放喷嘴材料热稳定性和不同材料结合风险。
- 原逻辑还整体排除了逐对象打印，无法区分“每个对象单独使用一种材料”和“同一对象内部混用高低温材料”。

## 5. 修复方案

### 修复思路

- 参考 Bambu Studio 的任务级安全校验语义，不再按物理喷嘴数量或具体机型跳过检查。
- 逐层打印：检查当前打印板实际使用的全部逻辑耗材。
- 逐对象打印：按对象分别收集模型区域、零件/涂色、层高范围及显式支撑耗材，再分别检查，避免两个单材料对象顺序打印时被误判。
- 保持现有高温组/低温组材料分类和错误提示，不新增 K3 特判、喷嘴映射分组规则或允许危险混打的偏好开关。

### 修改点

- 文件：`src/libslic3r/Print.cpp`
  - `Print::validate()`：删除 `nozzle_diameter.size() < 2` 和“非逐对象打印”的入口限制，只要实际使用材料数大于 1 就进入材料兼容性检查。
  - `Print::check_multi_filament_valid()`：抽取统一的耗材类型检查逻辑。
  - 逐层打印继续复用 `multi_filament_check_extruders()`，只检查当前板实际使用的耗材。
  - 逐对象打印按对象收集并去重耗材编号，同一对象内同时使用高温组和低温组材料时返回原有错误。

## 6. 验证清单

### 必测场景

- [ ] i7/普通单喷嘴，PLA 单材料：不报错。
- [ ] i7/普通单喷嘴，PLA + ABS：显示高低温耗材混合打印错误。
- [ ] K3，PLA 单材料：不报错。
- [ ] K3，PLA + ABS，映射到同一物理喷嘴：显示错误。
- [ ] K3，PLA + ABS，映射到不同物理喷嘴：按整板安全规则显示错误。
- [ ] 模型使用 PLA、支撑显式使用 ABS：显示错误。

### 边界场景

- [ ] 耗材列表中存在 ABS，但当前打印板未实际使用：不报错。
- [ ] 同温度组的多个材料共同打印：不报错。
- [ ] 未识别材料类型与单一高温组或低温组材料共同打印：保持原有兼容性规则。
- [ ] 层高范围、零件或多材料涂色引入高低温材料：显示错误。

### 反向场景

- [ ] 逐对象打印：对象 1 仅使用 PLA、对象 2 仅使用 ABS，不报错。
- [ ] 逐对象打印：同一对象内部使用 PLA + ABS，显示错误。
- [ ] 逐对象打印：同一对象模型使用 PLA、支撑使用 ABS，显示错误。
- [ ] 单材料切片、预览和导出 G-code 流程不受影响。

### 编译/测试结果

- 已执行：源码严格 UTF-8、无 BOM、最小差异、`git diff --check` 和明显乱码静态检查。
- 未执行：按工程规范，本次未编译；尚未进行 GUI 实际切片和设备打印验证。

## 7. 风险与回退

### 可能风险

- K3 上高低温材料即使映射到不同物理喷嘴，也会按 Bambu Studio 的整板安全规则阻止切片，行为比修复前更严格。
- 逐对象打印的材料收集范围扩大后，同一对象的层高范围、角色耗材或支撑耗材可能触发此前缺失的错误。

### 风险影响范围

- 仅影响实际使用两种及以上逻辑耗材时的切片前温度兼容性校验。
- 不修改耗材映射、喷嘴切换、冲刷、切片路径和 G-code 生成逻辑。

### 回退方案

- 回退 `src/libslic3r/Print.cpp` 中本次对 `Print::validate()` 和 `Print::check_multi_filament_valid()` 的修改。
- 删除本说明文档即可恢复修复前代码与文档状态。

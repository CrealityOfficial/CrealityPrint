## 2. 问题现象

- 禅道描述：在创建喷嘴页面中点击参考模板，不显示内容与选择列表；期望正常显示。
- 页面上的参考厂商、型号控件存在，但无法正常选择模板。
- 影响：用户无法通过参考模板填充新喷嘴的层高限制和回抽长度。

## 3. 影响范围

- 模块：准备页面 / 创建喷嘴对话框。
- 代码文件：src/slic3r/GUI/CreatePresetsDialog.cpp、src/slic3r/GUI/CreatePresetsDialog.hpp。
- 涉及流程：参考模板初始化、厂商与型号联动、目标打印机切换、模板参数回填。
- 创建打印机与创建喷嘴共用部分控件和加载函数，需要同时回归。

## 4. 修复前复现步骤

1. 打开创建喷嘴对话框。
2. 选择目标打印机和待创建的喷嘴直径。
3. 点击“参考模板”的厂商、型号下拉框。
4. 观察列表没有正常填充，无法选择参考模板。

第 2 步为结合代码补充的复现上下文；禅道原文仅描述进入创建喷嘴页面后点击参考模板。

## 5. 根因分析

以下结论来自代码及 Git 历史分析，非禅道原文：

- data_init() 在 m_type == 1（创建喷嘴）分支中，绑定目标打印机选择事件后立即返回。
- 厂商选项填充、型号选择事件、厂商联动事件原本位于该返回之后，导致创建喷嘴模式跳过公共初始化。
- 恢复模板选择后，原 on_preset_model_value_change() 会继续调用 update_printer_other_data_new()，按模板喷嘴直径重新设置直径选择，可能覆盖用户要创建的新规格。
- 默认同步第一页参考模板后，构造函数若继续初始化第二页的预设单选项，会尝试使用尚未选择的第二页模板加载预设。当前创建喷嘴已改为第一页直接保存，无需这条旧路径。
- 模型查找前未清空已选型号缓存，匹配失败时可能沿用上一次的型号信息。

## 6. 修复策略

- 将厂商选项填充和厂商、型号事件绑定移到模式分支之前，确保两种模式都完成公共初始化。
- 保留创建喷嘴专用的目标打印机事件分支，避免将另一模式的事件处理一并绑定。
- 增加 sync_nozzle_reference_template()，首次选择及切换目标打印机时，匹配其厂商、型号和参考规格；匹配不到时保留选择提示。
- 默认同步只更新模板选择，保留目标打印机当前编辑中的参数；用户主动选择其他模板后再回填参数。
- 切换厂商先清空旧型号及缓存，模板排序读取当前直径选择。
- 创建喷嘴选择模板后只更新最小层高、最大层高和回抽长度，随后返回，不更新目标直径或热床参数。
- 模板加载失败时重置型号选择和缓存；每次加载前清空旧型号匹配结果。
- 创建喷嘴模式跳过第二页预设单选项初始化，保持第一页直接保存流程。

## 11. 喷嘴规格显示说明

用户后续截图显示创建“0.3-标准”后，下拉列表同时包含“0.4-标准”和“0.3-标准”，当前选中“0.3-标准”。

代码核对结果：add_nozzle_variant_to_printer() 会保留原有基础规格，再追加新规格。因此原有 0.4 加新增 0.3 会显示两个可选规格；这不是新增两个相同规格，也不表示增加了两个物理喷嘴。

该行为在本次修复之前已经存在。用户本次决定先保持现状，本文记录该行为，不修改喷嘴变体的追加和保存规则。用户截图不作为上述界面回归清单全部通过的依据。

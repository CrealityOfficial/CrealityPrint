## 2. 问题现象

导入禅道附件并执行单盘切片后，模型没有使用耗材丝 1，但预览区“喷嘴耗材分组”仍然显示耗材丝 1 的分组信息。

期望结果：单盘预览只显示本盘最终切片结果中实际参与挤出的耗材，不显示仅存在于项目耗材列表、分组弹窗或模型配置中但未生成挤出路径的耗材。

## 3. 复现步骤

1. 导入 Bug 18140 的附件工程。
2. 确认当前盘模型没有使用耗材丝 1。
3. 点击“切片单盘”。
4. 进入预览区，查看“喷嘴耗材分组”。

修复前结果：分组卡片包含未使用的耗材丝 1。

修复后预期：分组卡片只包含切片结果中实际生成挤出路径的耗材。

## 4. 根因分析

### 原数据链路

预览区原先没有以最终切片结果作为唯一数据源：

```text
project_config["filament_map"]
    + 当前打印机预设的 nozzle_diameter
    + 当前盘 PartPlate::get_extruders(true)
    + 项目耗材预设、侧栏颜色
    -> GLCanvas3D 喷嘴耗材分组
```

该链路描述的是切片前的项目配置和模型耗材引用，不等同于 G-code 中实际产生挤出动作的耗材集合。项目中存在但当前盘未真正参与切片的耗材可能因此进入预览分组。

此外，切片结果尚未生成时就创建分组卡片，会先显示项目侧数据；切片完成后再切换数据则可能造成内容闪变，并使用户误认为预览数据就是最终切片结果。

### 最终切片结果中的权威字段

`GCodeProcessorResult` 已提供预览所需数据：

- `generated_filament_map`：本次 G-code 使用的耗材到物理喷嘴映射，喷嘴编号为 1-based。
- `generated_filament_map_present`：切片结果是否包含有效映射。
- `rendered_extruder_used`：G-code 解析过程中遇到实际挤出动作时记录的耗材使用标记。
- `nozzle_diameters`：本次切片结果的物理喷嘴信息。
- `creality_extruder_types`：切片结果携带的耗材类型。
- `creality_complete_extruder_colors` / `extruder_colors`：切片结果携带的耗材颜色。

其中 `rendered_extruder_used` 在处理 `EMoveType::Extrude` 或 `EMoveType::Extrude_Alter` 时设置，因此比项目耗材列表或模型预配置更适合判断预览中应显示哪些耗材。

## 5. 修复方案

### 修复原则

预览区喷嘴耗材分组改为只展示最终切片结果，不再使用项目配置、分组弹窗、耗材侧栏或模型引用作为显示回退数据。

```text
切片结果尚未完成
    -> 不创建喷嘴耗材分组卡片

切片成功且结果有效
    -> generated_filament_map 确定喷嘴分组
    -> rendered_extruder_used 过滤实际使用耗材
    -> 切片结果中的类型和颜色绘制卡片
```

### 修改点

修改 `src/slic3r/GUI/GLCanvas3D.cpp`：

1. `render_filament_nozzle_mapping_preview_summary()` 仅在以下条件全部满足时读取并绘制数据：
   - 当前没有正在进行的切片任务；
   - 当前盘存在且 `is_slice_result_valid()` 为真；
   - `GCodeProcessorResult` 存在；
   - `generated_filament_map_present` 为真；
   - `generated_filament_map` 非空。
2. 删除预览分组对 `project_config["filament_map"]`、`PartPlate::get_extruders(true)`、项目耗材预设和侧栏颜色的依赖。
3. 遍历 `generated_filament_map` 时，仅将 `rendered_extruder_used[filament] == true` 的耗材加入对应喷嘴卡片。
4. 喷嘴数量优先读取切片结果的 `nozzle_diameters`；旧结果缺少该字段时，根据结果映射中的最大喷嘴编号回退推导，最多显示 4 个喷嘴。
5. 耗材类型和颜色只读取切片结果；缺少类型或颜色时分别显示通用名称和默认色，不回退到当前项目的可变状态。
6. 外层 `separate_grouping_panel` 增加有效切片分组结果判断。切片前、切片中、失败或取消后均不创建该卡片，避免出现空白面板或过渡数据。
7. 切片完成流程已有 `m_is_slicing = false` 和 `request_extra_frame()`，无需新增事件；下一帧会使用新生成的切片结果显示分组。

## 6. 混色耗材说明

本次修改以 G-code 实际耗材 ID 为准，不再在预览层使用项目中的混色耗材定义进行二次展开。

- 如果混色切片最终以组成它的物理耗材生成挤出路径，`rendered_extruder_used` 会标记这些物理耗材，预览显示对应物理耗材。
- 如果切片结果保留虚拟混色耗材 ID，则预览按该结果 ID 及其 `generated_filament_map` 展示。
- 预览层不再根据当前项目配置推测或改写切片结果，避免界面分组与实际 G-code 不一致。

## 8. 风险与回退

### 风险

- 卡片现在严格依赖切片结果；旧 G-code 或异常结果未携带分组映射时不会显示该卡片。
- 结果中的耗材类型、颜色不完整时会显示默认信息，这是保持“切片结果唯一数据源”的预期取舍。
- 混色耗材展示语义由实际 G-code 耗材 ID 决定，不再保证与切片前分组弹窗的虚拟耗材名称一致。

### 回退

如需恢复原行为，可回退 `GLCanvas3D.cpp` 中以下两部分：

1. `render_filament_nozzle_mapping_preview_summary()` 的切片结果唯一数据源逻辑。
2. `_render_printer_preset_and_obj_list()` 中 `has_filament_grouping_result` 对外层卡片的显示限制。

回退后预览区将重新读取项目配置和当前盘模型耗材，Bug 18140 中未使用耗材被显示的问题可能再次出现。

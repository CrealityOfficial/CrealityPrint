# Bug 16282 F039 色塔参数不生效

## 1. 基本信息
- Bug ID：16282
- 标题：【F039】【切片】色塔参数不生效
- 反馈人：康美樱
- 处理人：wangwenbin
- 影响模块/影响文件：工艺参数界面、色塔参数显示控制；`src/slic3r/GUI/Tab.cpp`

## 2. 现象与复现
- 复现场景：选择 F039 机型，进入工艺参数页面，查看或调整色塔相关参数。
- 实际结果：色塔参数在界面上可见，但修改后对切片结果没有实际作用，用户容易误以为该参数可以影响切片。
- 期望结果：无实际作用的参数不应暴露给用户，避免产生无效配置和误导。

- commit hash：未定位到单一责任提交
- Author：无

## 4. 根因分析
- 触发条件：F039 工艺参数页展示了色塔相关配置项。
- 代码链路：参数界面根据机型和配置定义生成工艺参数控件，但色塔参数没有接入实际切片链路，切片生成时不会消费该设置。
- 为什么会出现该现象：该参数目前仅作为界面配置项存在，没有对应的有效算法或 G-code 输出逻辑，因此用户修改参数后不会改变色塔或切片结果。

## 5. 修复方案
- 修复思路：在功能没有实际切片作用前，先屏蔽色塔参数入口，避免用户配置无效选项。
- 修改点：在 `Tab.cpp` 的工艺参数显示逻辑中，对 F039 相关色塔参数做隐藏/屏蔽处理。
- 为什么这样改：相比保留一个不生效的参数，隐藏该选项更符合当前功能状态，也能减少用户误操作和问题反馈。

## 6. 影响范围与风险
- 正向影响：F039 工艺页面不再展示无实际作用的色塔参数，降低用户误解。
- 可能风险：如果后续色塔功能重新接入切片链路，需要同步恢复该参数入口并补充回归验证。
- 是否改变旧行为：改变界面展示行为；不改变实际切片结果，因为该参数原本也没有被有效使用。

## 7. 回归建议
- 必测场景：选择 F039 机型，确认工艺参数页中色塔相关无效选项不再显示。
- 必测场景：切片普通单色、多色模型，确认切片流程正常，不因屏蔽选项产生报错。
- 边界场景：切换到非 F039 机型，确认其他机型参数显示不受影响。
- 反向场景：加载旧 3MF 或旧项目文件，确认即使文件中保存了色塔参数，也不会导致界面异常或切片异常。

# Bug 16338 F039 冲刷体积配置入口隐藏后不再提示冲刷乘数警告

## 1. 基本信息
- Bug ID: `16338`
- 标题: `【F039】【切片】F039机器在耗材栏没有显示冲刷体积配置项，还需不需要走冲刷体积的系数判断？`
- 反馈人: 测试反馈
- 处理人: `wangwenbin`
- 影响模块/影响文件:
  - `src/libslic3r/Print.cpp`
  - 耗材栏冲刷体积入口
  - 切片前参数校验警告

## 2. 现象与复现
- 复现场景:
  - 选择 F039 这类多喷嘴机型。
  - 耗材栏中冲刷体积配置入口已按需求隐藏。
  - 当前工程或机器默认参数中 `flush_multiplier` 低于 Creality CFS 默认要求值。
- 实际结果:
  - 页面仍弹出黄色警告: `冲刷乘数设置太低，值是 1.00 跳转到 (flush_multiplier)`。
  - 但 F039 机型已不显示冲刷体积配置入口，用户无法通过该入口处理该警告。
- 期望结果:
  - F039 这类多喷嘴机型既然已经隐藏冲刷体积相关入口，就不再触发 `flush_multiplier` 过低警告。
  - K2 Plus 等非多喷嘴机型仍保留原有冲刷乘数校验和警告逻辑。

## 3. 责任提交追溯
- 本问题属于冲刷体积入口屏蔽后的关联校验遗漏。
- 暂未追溯到独立责任提交。

## 4. 根因分析
- 触发条件:
  - `Print::validate()` 中只判断了是否存在擦料塔、`flush_multiplier` 是否大于 0，以及是否低于最小建议值。
  - 该校验没有同步判断当前是否为多喷嘴机型。
- 代码链路:
  - UI 层已对 F039 这类多喷嘴机型隐藏冲刷体积按钮。
  - 切片校验阶段仍进入 `Print::validate()`。
  - `Print::validate()` 继续执行 `flush_multiplier` 过低检查并设置 `warning_key = "flush_multiplier"`。
- 为什么会出现该现象:
  - 按钮隐藏只影响用户入口，不会自动影响后台参数校验。
  - 因此出现了“配置入口不可见，但仍提示用户跳转到该配置项”的不一致体验。

## 5. 修复方案
- 修复思路:
  - 将冲刷乘数过低警告与冲刷体积配置入口的适用机型保持一致。
  - 多喷嘴机型不显示冲刷体积配置入口，因此不再走 `flush_multiplier` 过低警告。
  - 非多喷嘴机型保持旧逻辑，避免误伤 K2 Plus 等机型。
- 修改点:
  - `src/libslic3r/Print.cpp`
  - 在 `Print::validate()` 的 `flush_multiplier` 警告判断前增加多喷嘴机型识别:
    - `!single_extruder_multi_material`
    - `nozzle_diameter.values.size() > 1`
  - 仅当不是多喷嘴机型时，才继续检查 `flush_multiplier` 是否过低。
- 为什么这样改:
  - F039 这类多喷嘴机型已经不提供冲刷体积配置入口，继续提示用户修改 `flush_multiplier` 没有实际操作路径。
  - 该修复只收敛警告触发条件，不改变非多喷嘴机型原有行为。

## 6. 影响范围与风险
- 正向影响:
  - F039 多喷嘴机型不再出现不可处理的冲刷乘数警告。
  - UI 入口显示逻辑与切片校验逻辑保持一致。
- 可能风险:
  - 如果后续某些多喷嘴机型重新启用冲刷体积配置入口，需要同步恢复或调整该校验条件。
- 是否改变旧行为:
  - 改变多喷嘴机型的警告行为: 不再提示 `flush_multiplier` 过低。
  - 不改变非多喷嘴机型的警告行为。

## 7. 回归建议
- 必测场景:
  - 选择 F039，多耗材场景下确认耗材栏无冲刷体积按钮，且不再弹出 `flush_multiplier` 过低警告。
  - 选择 F039，切片流程可正常继续。
- 边界场景:
  - F039 的 `flush_multiplier = 1.00`，`default_flush_multiplier > 1.00` 时不报警。
  - 多喷嘴机型切换到非多喷嘴机型后，警告状态可按当前机型重新刷新。
- 反向场景:
  - 选择 K2 Plus 等非多喷嘴机型，若 `flush_multiplier` 低于要求值，仍应提示冲刷乘数过低。
  - 非多喷嘴机型冲刷体积按钮仍按原逻辑显示和使用。

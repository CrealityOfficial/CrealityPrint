## 2. 问题现象

- 用户反馈现象：导入附件 3MF 并完成切片后，擦拭塔尺寸异常增大，占用大面积打印平台。
- 实际结果：预览中的擦拭塔宽度达到约 `205.5 mm`，远大于模型及正常擦拭塔尺寸，并出现超出热床边界的 G-code 路径提示。
- 期望结果：擦拭塔应根据正常可打印层高和冲刷体积规划，尺寸保持在合理范围内，不应因多对象层 Z 交错而异常放大。

## 3. 复现步骤

### 前置条件

- 机型：F039
- 打印顺序：逐层打印（`by layer`）
- 模型：两个球体，分别使用耗材 1 和耗材 2
- 层高：一个对象使用固定 `0.08 mm` 层高，另一个对象包含约 `0.08～0.32 mm` 的自适应层高配置
- 擦拭塔：启用肋墙方形擦拭塔，`prime_volume=45 mm³`，`prime_tower_width=40 mm`

### 操作步骤

1. 导入 `球2.3mf`。
2. 保留 3MF 中的 F039、耗材映射、层高和擦拭塔配置。
3. 执行切片。
4. 进入 G-code 预览并观察擦拭塔尺寸。

### 复现结果

- 擦拭塔异常放大到约 `205.5 mm` 宽。
- 运行日志显示擦拭塔规划经过 `WipeTowerCreality` 路径。
- 复现日志共捕获到 84 次异常层高计算，最小层高为 `0.00040122 mm`；对应的最大擦拭路径长度为 `224354 mm`，最大预留深度为 `5218 mm`。

### 复现概率

- 使用附件 3MF 可稳定复现。

## 4. 根因分析

### 触发条件

1. 同一打印盘存在多个对象。
2. 对象使用不同的层高序列，例如固定层高与自适应层高并存。
3. 不同对象使用不同耗材，交错的公共 Z 层上频繁发生耗材切换。
4. 启用擦拭塔，冲刷体积需要转换为擦拭塔内的挤出路径长度。

### 代码链路

1. `ToolOrdering` 汇总所有对象的打印 Z，形成公共 `LayerTools` 序列。
2. `ToolOrdering::fill_wipe_tower_partitions()` 使用当前擦拭塔 Z 与上一个擦拭塔 Z 的差值计算 `wipe_tower_layer_height`。
3. 固定层高对象与自适应层高对象的 Z 序列交错后，相邻公共 Z 差可能仅为 `0.0004～0.02 mm`，但该差值并不是当前对象真实的可打印层高。
4. `Print::_make_wipe_tower()` 原先直接把 `wipe_tower_layer_height` 传给 `WipeTowerCreality::plan_toolchange()` 或 `WipeTowerCrealityCFS::plan_toolchange()`。
5. 擦拭塔通过“冲刷体积 ÷ 挤出截面积”计算路径长度；挤出截面积与层高成正比，因此异常小的层高会将固定冲刷体积放大为数万至数十万毫米的路径。
6. 方形擦拭塔再根据所需路径深度计算边长，最终形成异常巨大的擦拭塔。

### 问题原因

`wipe_tower_layer_height` 表示相邻擦拭塔事件的几何 Z 间距。在多对象不同层高交错时，它不能直接代表当前对象的实际挤出层高。原逻辑混用了“公共 Z 间距”和“挤出计算层高”两种语义，导致擦拭路径及塔尺寸被成倍放大。

BambuStudio 参考代码同样直接使用相邻擦拭塔 Z 差进行规划，该实现建立在层高序列不会产生异常微小交错间距的前提上，不能直接解决本附件模型的触发场景。

## 5. 修复方案

### 修复思路

在 Creality 擦拭塔规划入口区分两种层高语义：

- 保留 `wipe_tower_layer_height`，用于正常擦拭塔层间距及稀疏层场景。
- 使用 `LayerTools::layer_height` 表示当前对象或支撑层的真实可打印层高。
- 实际传给擦拭塔挤出规划的层高取两者较大值：

```cpp
wipe_tower_extrusion_height = max(wipe_tower_layer_height, layer_height);
```

该处理不会使用固定阈值，也不会修改对象层高、公共 Z 顺序、耗材切换顺序或冲刷体积。正常情况下两个值相同或擦拭塔层间距更大，原行为保持不变；仅在多对象 Z 交错导致公共间距异常小时，使用当前层的真实层高进行挤出计算。

### 修改点

- 文件：`src/libslic3r/Print.cpp`
- 函数：`Print::_make_wipe_tower()`
- 修改内容：
  - 为 `WipeTowerCrealityCFS` 规划路径计算 `wipe_tower_extrusion_height`，同层的空切换和实际耗材切换统一使用该值。
  - 为 `WipeTowerCreality` 规划路径计算 `wipe_tower_extrusion_height`，同层的空切换和实际耗材切换统一使用该值。
  - 未修改 BBL `WipeTower` 和非固件软多材料机型的 `WipeTower2` 路径，控制本次 F039 修复范围。

## 7. 风险与回退

### 可能风险

- `LayerTools::layer_height` 在多个对象恰好共享同一 Z 时可能来自最后一次收集到的对象层；本方案通过取两种层高的较大值避免比原擦拭塔层间距更小。
- 修改同时覆盖两条 Creality 擦拭塔规划路径，需要分别验证冲刷进塔和普通擦拭两类配置。

### 风险影响范围

- 仅影响固件软多材料机型进入 `WipeTowerCreality` 或 `WipeTowerCrealityCFS` 时的擦拭塔挤出层高参数。
- 不影响模型切层、自适应层高生成、耗材映射及其他擦拭塔实现。

### 回退方案

- 回退 `src/libslic3r/Print.cpp` 中 `wipe_tower_extrusion_height` 的计算及四处参数替换，恢复直接传递 `layer_tools.wipe_tower_layer_height`。

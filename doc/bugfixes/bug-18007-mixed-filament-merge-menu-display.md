## 2. 问题现象

### 2.1 禅道原始问题

1. 将 Creality Print 窗口全屏或最大化。
2. 在准备页创建较多物理耗材和混色耗材。
3. 点击混色耗材列表中的合并按钮。
4. 合并目标弹窗高度随候选数量持续增长，可能显示不全或延伸到副屏。

期望：合并目标在当前操作区域内正常显示，所有候选项均可访问。

### 2.2 调试期间确认的关联问题

- 合并按钮使用的自绘弹窗与物理耗材卡片“合并到”菜单外观和行为不一致。
- 1080p 屏幕上，鼠标滚轮位于耗材卡片或卡片内部按钮时，可能没有执行“一档滚动一行”的逻辑。
- 1080p 或 125% 等缩放比例下，选中耗材卡片的绿色边框存在上、左侧比下、右侧更粗的现象。

## 3. 根因分析

### 3.1 合并弹窗

- 混色耗材合并按钮原先创建 `MixedFilamentMergeMenu` 自绘瞬态窗口。
- 所有候选项直接加入纵向 sizer，并通过 `SetSizerAndFit()` 一次性展开。
- 当物理耗材数量较多时，窗口高度超过当前显示器工作区。
- 弹窗由按钮屏幕坐标手动定位，Windows 多显示器环境下可能跨到相邻屏幕。

### 3.2 1080p 滚轮步长

- 耗材列表的滚动窗口已将垂直滚动单位设为一行卡片高度。
- `wxEVT_MOUSEWHEEL` 最初只绑定在 `wxScrolledWindow` 上。
- 鼠标位于 `FilamentItem`、`FilamentButton` 或内部图标时，鼠标事件可能由子窗口接收，滚动容器的一行滚动处理无法稳定执行。
- `wxWrapSizer` 的实际列数还可能与预估列数不同，使预估内容高度和实际排布不一致。

### 3.3 选中绿色边框

- 选中框使用整数坐标的 `wxDC::DrawRoundedRectangle()` 绘制。
- 边框宽度为 `FromDIP(2)`；在 125% 等缩放下可能换算为奇数物理像素。
- 奇数宽度画笔以整数边界为中心时，四条边的像素覆盖和裁剪不完全对称，表现为上、左边较粗。

## 4. 修复方案

### 4.1 复用原生合并菜单

- 删除混色耗材合并按钮专用的 `MixedFilamentMergeItem` 和 `MixedFilamentMergeMenu` 自绘窗口。
- 改用与物理耗材卡片“合并到”一致的原生 `wxMenu`。
- 菜单项统一显示：
  - 两位耗材编号；
  - 耗材颜色方块；
  - 当前耗材名称或混色描述。
- 使用 `GetPopupMenuSelectionFromUser()` 从合并按钮下方弹出菜单。
- 由操作系统负责菜单在当前显示器工作区内的边缘调整和长菜单处理，避免手动坐标导致跨屏。
- 保留原有合并目标类型、索引和 `merge_mixed_filament()` 业务逻辑。

### 4.2 统一耗材区滚轮事件

- 将滚轮处理提取为 `FilamentPanel::on_filament_wheel()`。
- 在以下窗口上绑定同一处理：
  - `m_filament_scrolled`；
  - `m_filament_content`；
  - 每个 `FilamentItem`；
  - 卡片内的 `FilamentButton` 和图标子窗口。
- 累计高精度滚轮 rotation；每达到一个标准 wheel delta 后滚动一个实际卡片行。
- 布局完成后读取 `wxWrapSizer` 生成的卡片坐标，计算：
  - 实际行间距；
  - 实际内容高度；
  - 最终 virtual size。
- 卡片高度保持当前设计值 `46 DIP`。

### 4.3 对称绘制选中框

- 使用 `wxGraphicsContext` 绘制绿色选中框。
- 边框宽度仍为 `FromDIP(2)`。
- 使用 `border_width / 2.0` 作为四边浮点内缩值。
- 绘制宽高分别减去完整边框宽度，使画笔全部位于控件区域内。
- 使用透明画刷，仅覆盖边框，不改变卡片原有颜色与内容。

## 5. 代码改动摘要

### `src/slic3r/GUI/Plater.cpp`

- `Sidebar::show_mixed_filament_merge_menu()` 改为创建原生 `wxMenu`。
- 根据物理耗材和可用混色耗材生成带色块的菜单项。
- 记录菜单项 ID 到目标类型、目标索引的映射。
- 用户选择后继续调用原有 `merge_mixed_filament()`。
- 删除专用自绘合并菜单类和相关绘制代码。

### `src/slic3r/GUI/FilamentPanel.h`

- 新增 `FilamentPanel::on_filament_wheel(wxMouseEvent&)` 声明。
- `FILAMENT_BTN_HEIGHT` 保持为 `46`。

### `src/slic3r/GUI/FilamentPanel.cpp`

- 将耗材列表滚轮逻辑提取为成员函数并绑定到卡片层级中的相关窗口。
- 根据实际布局坐标校准滚动单位和 virtual height。
- 选中边框改用 `wxGraphicsContext` 浮点坐标绘制。

## 7. 风险与回滚

- 风险等级：`低到中`。
- 修改集中在准备页耗材菜单、滚轮事件和选中态绘制，不修改耗材数据结构、混色计算或切片逻辑。
- 原生菜单在 Windows、macOS 和 GTK 下由系统实现，外观及长菜单导航可能存在平台差异，需要分别回归。
- 多个子窗口绑定同一滚轮处理后，需要确认单次滚轮事件不会被重复处理；当前处理函数消费正常垂直滚轮事件，不再继续传播。
- 回滚方式：
  - 恢复 `MixedFilamentMergeItem` 和 `MixedFilamentMergeMenu`；
  - 恢复滚轮仅绑定到滚动窗口的实现；
  - 恢复 `wxDC` 整数坐标选中框绘制。

## 8. 结论

本次修改用项目内已有的原生“合并到”菜单替换混色列表专用自绘弹窗，消除候选项过多时的固定高度和手动跨屏定位问题；同时完善了 1080p 下的整行滚动事件覆盖，并修正高 DPI 下耗材卡片选中框四边粗细不一致的问题。代码已完成增量编译，最终发布前仍需按第 6.2 节执行真实多显示器和多 DPI 人工回归。
